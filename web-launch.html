Tower of the Sorcerer — browser backend switch

Both builds are real, separately-compiled Emscripten outputs of the same game (same IRenderer interface). Open each in a browser tab and screenshot.

▶ WebGL2 build ▶ WebGPU build

WebGL2: universal browser support. WebGPU: Chrome/Edge (experimental in Emscripten 6.0.6, via --use-port=emdawnwebgpu). If a browser lacks WebGPU, the WebGPU tab will log an adapter/device error in the console.

Rebuild from source:
WebGL2: emcmake cmake -S . -B build-web -DWEB=ON && cmake --build build-web -j4
WebGPU: emcmake cmake -S . -B build-webgpu -DWEB=ON -DWEB_BACKEND=WebGPU && cmake --build build-webgpu -j4

## Watch out

- **A character file must not contain the weapon.** Its contract is `body` / `hand`, and the weapon is its own file,
  named with the character file in the weapon's `battleAnim`.
- **After any atlas rebuild or restyle, run `python tools/refresh_meshes.py`.** The atlas tool no longer touches
  meshes. `--check` tells whether they are current.
- **A mesh file is shared by every clip of its atlas.** Saving a clip only adds its meshes; removing unused ones
  (`--prune`) needs the full list of clips, which `refresh_meshes.py` gives.
- **Open `art_raw/atlas/game.atlasproj` in the atlas editor, not `assets/media/atlas/game.atlas`.** Opening the cooked
  atlas makes a second project beside it (that is where the stray files came from).
- **A looping node loops every key under it.** The bow's `charge` therefore holds two copies of the bow; see
  [../15_ANIMATION.md](../15_ANIMATION.md).
- **Generated files:** `weapon_bow.anim` and `archer_bow.anim` are written by their scripts. Change the scripts rather
  than the files.
- **Scroll bars are sliders too:** the wheel guard in `Theme.cpp` must leave them alone, or a scroll area loops
  forever.

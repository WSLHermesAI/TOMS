## Watch out

- **New singletons:** one that keeps memory in a pointer must register with `toms::onReleaseSingletons`, or the leak
  check lists it.
- **Handlers on the global event bus:** an object that can be destroyed must use `listen()` and keep the
  `Subscription`, never `subscribe()` with `this`.
- **The player menu has six tabs now** (Cards before System): `player.rml` shows them by number.
- **Shared test scenarios:** a scenario folder is test data. A change to it runs its own `scenario.<name>` test.

## 注意

- **web glTF 檢視器和遊戲共用 `Build\web-release-windows`**。`build_web.cmd` 接受第二個參數，也就是要建置的目標
  （`gltf_viewer`）；沒有給時只建遊戲。
- **web 上：沒有陰影貼圖、沒有 MSAA。** WebGL 上的陰影本來就關閉（2026-10-05 的連結失敗）；MSAA 會讓頁面當掉。
- **`fs_mesh.sc` 的取樣器 stage：** 7 和 8 是 specular 貼圖，9 是環境 cubemap（6 是群體的動畫貼圖）。新貼圖需要空的 stage。
- **環境的方向是 Khronos 檢視器的方向**（照片的中間一欄朝 +Z）；在 `gltf_environment.cpp` 裡轉動它，我們的截圖就會和他們的不同。
- **開啟環境時，檢視器的 ambient 滑桿和天空 / 地面顏色沒有作用**；它的強度在 Environment 區。

## 注意

- **弓與格子：** 一根手指無法在拉弓時點格子。電腦上方向鍵可用；手機上可能不順手。
- **長手機：** 格子在畫面中間，離拇指較遠。
- **這三隻怪物** 除了第一層的範例外都不在樓層上，地圖與卡片圖示仍是史萊姆。數值是複製的，還沒調整。
- **第一層那場戰鬥** 對新角色可能偏難。從該項目刪除 `party` 即可還原。尚未確認關卡編輯器存檔時是否保留 `party`。
- **第一箭的提示**（「往後拉再放開」）在第一次射擊前會壓到怪物的名字或 HP 條。
- **ComfyUI** 為了繪圖啟動，之後已關閉。`--use` 不需要伺服器；`--paint` 需要。

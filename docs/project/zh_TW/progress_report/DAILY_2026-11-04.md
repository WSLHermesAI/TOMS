## 注意

- **桌面版的值依資料夾而定：** 存檔資料夾是工作目錄下的 `save`，所以從別的資料夾啟動遊戲會有自己的輪流順序。這個值不在 git 中（`save/` 被忽略）。
- **網頁版與 Android 最多 48 個關節：** 超過的 skin 只有前 48 個會動。大型角色骨架在那裡需要把關節放進貼圖。城市沒有 skin，所以沒有影響。
- **電腦看不出行動裝置的限制：** 超過限制的著色器在這裡可以連結，在裝置上卻什麼也不畫，也沒有錯誤。網頁測試會檢查 ES 3.0 限制，但只有執行網頁測試時才會；`tools\test.cmd` 不一定會選到它們。
- **測試會隱藏版本**（`--fixed-dt`），所以參考圖不會顯示它，也沒有測試檢查畫面上的角落。
- **檢視器的「Save settings」不會影響標題，** 標題的外觀寫在 `title_scene.cpp`。
- **sha 是最後一個 commit：** 發佈時未提交的變更會在建置中，但不在該 commit 中。
- **從 Git Bash 執行 `emsdk_env.bat`** 會設定 bash 式的路徑，`tools\build_web.cmd` 接著會說找不到 emsdk；請在 PowerShell 或命令提示字元中建置網頁版。
- **仍然粗糙：** sunset 預設有點卡通；雲可能飄到標題的副標題後面，讓它變淡。

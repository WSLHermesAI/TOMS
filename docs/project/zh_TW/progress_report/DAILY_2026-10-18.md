## 注意

- **物件 id 是玩家存檔的一部分：**已發佈的樓層不要手動重新編號。HTML 關卡編輯器會保留物件的 id，但不會給新物件 id（Qt 編輯器
  或 `tools/add_stage_uids.py` 會給）。
- **較新版本的存檔是唯讀的：**可以遊玩，但不會寫入那一格。
- **換皮改的是材質，不是形狀：**物件輪廓外不會長出東西，文字圖變化很小。
- **換皮計畫檔的 `"also"` 只是備註：**不支援兩個圖集把同一頁切成不同部件。
- **AI 像素圖是草稿：**數值依階而定，NPC 只有一句閒聊，道具是通用說明，都標記 `"draft": true`。

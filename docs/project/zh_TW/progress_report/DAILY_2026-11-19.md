## 注意

- **`ringY` 取決於主角的圖：** 他的圖畫得比框高，所以圓環高度是以框來設定（-0.12）。換主角圖或直式版面可能要另一個值；只在橫式檢查過。
- **有一次編譯失敗，而它之後的測試是在舊程式上通過的**（`game_ui.cpp` 中一個 `//` 註解吃掉了大括號）。已修正並重新編譯；上面的結果來自新版本。
- **情境的畫圈位置是固定的**（1024×768 時圓環中心在 140,359）：主角的框或 `ringY` 改變，圓環就會移動，`battle_ultimate_cyclone_full` 也要跟著改。
- **鏡頭平移與「low」鏡頭分屬 2D 與 3D：** 平移（`value`）作用在 2D 戰鬥；3D 場景用原本的「low」鏡頭，那裡沒有檢查過。

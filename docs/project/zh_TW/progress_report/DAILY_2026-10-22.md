## 注意

- **角色檔不可以包含武器。** 它的約定是 `body`／`hand`，武器是自己的檔案，並和角色檔一起寫在武器的 `battleAnim` 中。
- **任何圖集重建或換皮之後，執行 `python tools/refresh_meshes.py`。** 圖集工具不再處理網格。用 `--check` 可確認是否為最新。
- **網格檔由同一圖集的所有片段共用。** 儲存一個片段只會加入它的網格；要移除沒用到的網格（`--prune`）需要完整的片段清單，
  `refresh_meshes.py` 會提供。
- **在圖集編輯器中請開啟 `art_raw/atlas/game.atlasproj`，不要開 `assets/media/atlas/game.atlas`。** 開啟打包好的圖集會在旁邊
  多產生一個專案（多出來的檔案就是這樣來的）。
- **新遊戲現在會開啟武器試用。** 在標題畫面按 Enter 的自動執行需要 `--skip-start-story`（截圖測試會帶上它）；測試情境不會經過它（它們直接開新遊戲）。
- **畫面上的文字必須在 UI 字型中：** 新增文字後執行 `python tools/make_ui_font.py`（Windows 會用系統字型補上缺字，網頁與手機不會）。
- **循環節點會循環它底下的所有關鍵影格。** 所以弓的 `charge` 放了兩份弓；見 [../../../engine/zh_TW/05_ANIMATION.md](../../../engine/zh_TW/05_ANIMATION.md)。
- **產生出來的檔案：** `weapon_bow.anim` 與 `archer_bow.anim` 由腳本寫出。要修改請改腳本，而不是改檔案。
- **捲軸也是滑桿：** `Theme.cpp` 的滾輪保護必須略過捲軸，否則捲動區域會無限循環。

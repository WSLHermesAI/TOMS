## 注意

- **需要其他畫布的測試要自己帶 `--design` 或 `--window`**：smoke 測試和測試情境固定為 1024 × 768（最後一個 `--design` 為準）。
- **絕不把 UI 的位置複製進遊戲程式。** 遊戲在 UI 元素上繪製的地方，由 `GameUi::sync` 讀取版面再告訴遊戲（`setBattleBoxes`、
  `setComboPointsOnScreen`）；新增的也要這樣做。
- **以中央為基準擺放（`left: 50%; margin-left: ...`）時，橫向規則在 1024 畫布上逐像素不變**；會移動它們的修改會讓截圖參考圖失效。
- **Android 和網頁版在 gamma 空間混色，桌面版在線性空間**（`color_space.h`）：半透明效果在那裡看起來略有不同。要改就改這一個標頭檔，
  不要改使用它的檔案。
- **`tools\build_android.cmd` 的兩種除錯版寫到同一個 `app-debug.apk`**：`run_android.cmd` 安裝的是最後建置的那個。
- **一隻怪物必須逐像素不變。** `battle.rcss` 以 `.n1`–`.n3`（幾隻）與 `.f1` / `.f2`（哪一隻）擺放怪物；`.n1` 規則重現原本單隻怪物的框
  （1024 畫布上 652, 84, 134 × 134）。`.n2` / `.n3` 可以隨意改；改 `.n1` 會讓戰鬥截圖失效。
- **玩家的攻擊打向 `cs.target`，怪物的攻擊打向玩家。** 新的攻擊程式從 `cs.foes[cs.target]` 取怪物，最後呼叫 `afterPlayerHit`（它處理倒下、
  目標移動與勝利）；還有怪物站著時不要直接呼叫 `finishCombatWin`。

## Watch out

- **The desktop's value is per folder:** the save folder is `save` under the working directory, so starting the game from another folder
  starts its own turns. The value is not in git (`save/` is ignored).
- **Tests hide the version** (`--fixed-dt`), so a reference picture does not show it, and nothing tests the corner on screen.
- **The viewer's "Save settings" does not reach the title,** which has its own look in `title_scene.cpp`.
- **The sha is the last commit:** changes not committed at publish time are in the build, not in that commit.
- **`emsdk_env.bat` run from Git Bash** sets bash-style paths and `tools\build_web.cmd` then says emsdk is missing; run web builds from
  PowerShell or a command prompt.
- **Still rough:** the sunset preset is a little cartoonish; a cloud can drift behind the title's subtitle and fade it.

## Watch out

- **Object ids are part of players' saves:** do not renumber them by hand on a released floor. The HTML stage editor
  keeps an object's id but gives no id to a new one (the Qt editor or `tools/add_stage_uids.py` does).
- **A newer-version save is read-only:** the run plays, but nothing is written to that slot.
- **Reskins change materials, not shapes:** nothing can grow outside an object's silhouette, and text pictures change
  little.
- **The reskin plan's `"also"` is a note only:** two atlases cutting one page into different parts are not supported.
- **The AI sprites are drafts:** stats follow their tier, NPCs have one chat line, items a generic description, all
  marked `"draft": true`.

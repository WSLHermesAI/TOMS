## Watch out

- **A monster without `"moves"` strikes, exactly as before**, and the scenarios rely on it. A monster that gains moves
  changes its fights (the bat's jabs interrupt combos).
- **The default "Perfect!" result multiplies a full combo's damage by 1.2** for every weapon without its own
  `"results"`.
- **Lists in `.rml`: the `data-for` on a plain wrapper, the bindings on the element inside.** Bindings on the `data-for`
  element itself warn when the list shrinks.
- **The battle editor writes `enemies.json` in its own layout** (objects that fit 160 characters on one line); a
  hand edit in another layout is rewritten on its next save. `battle_editor.selftest` checks the file round-trips.
- **Each Qt editor copies its own Qt runtime** after it builds; a new Qt editor needs the same lines
  (`src/editor/CMakeLists.txt`).

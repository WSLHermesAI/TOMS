## Watch out

- **A test that wants another canvas passes its own `--design` or `--window`**: the smoke tests and scenarios pin
  1024 × 768 (the last `--design` wins).
- **Never copy a UI position into game code.** Where the game draws on a UI element, `GameUi::sync` reads the layout
  and tells the game (`setBattleBoxes`, `setComboPointsOnScreen`); a new one should do the same.
- **Landscape rules stay pixel-identical on the 1024 canvas** when placed from the centre (`left: 50%; margin-left:
  ...`); a change that moves them breaks the screenshot references.
- **Android and the web blend in gamma space, desktop in linear** (`color_space.h`): half-transparent effects look a
  little different there. Change the switch in that one header, not in the files that use it.
- **`tools\build_android.cmd`'s two debug kinds write the same `app-debug.apk`**: the last one built is what
  `run_android.cmd` installs.

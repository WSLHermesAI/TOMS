## Watch out

- **`tools/package_editors.cmd` deletes everything in `Editor/bin` it does not ship**, including a game run's
  `save/` folder. Move those aside first, or run `python tools/package_editors.py --check` to see what it would do.
- **The tutorial's painted weights belong to the golem's default mesh** (23 points). If the golem's art or mesh grid
  changes, `golem_done.anim` goes back to automatic weights; `anim.editor_selftest` then fails its "painted" check.
- **`docs/examples/` is scanned by `refresh_meshes.py`.** A practice file saved there with another mesh grid adds that
  mesh to `game.mesh.json`; delete the practice file and run `python tools/refresh_meshes.py` to take it out.
- **Weights mode paints every skin under the brush** that has the selected bone. Use Solo to paint one.
- **GitHub Pages takes minutes**: the deploy queues, then the page is cached for up to 10 minutes. Check
  `version.txt` on the site rather than the page.

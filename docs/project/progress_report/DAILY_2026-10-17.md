## Watch out

- **Debug builds of the editor** are several times slower than Release (the JSON library is not optimised there);
  use `Build\windows-release\bin\stage_event_editor.exe` for daily editing.
- **Hot reload is on in Debug game builds:** a broken file saved while playing keeps the old one on screen and logs why.
- **The `looks` table** (statuses beyond `idle` / `opening`) has no shipped data and no automated test yet.
- **The game's own `game.atlas`** is not hot-reloaded; an art style change reloads it.
- **Categories:** `editor_palette.json` exists only once a category is made; deleting a category never deletes a type.
- **Docs in two languages:** today's changes to 09, 19 and 25 are in both.

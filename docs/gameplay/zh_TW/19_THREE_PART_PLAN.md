- 點格子或用方向鍵移動。攻擊前，危險的格子變紅並逐漸填滿（`battle.json` `cells.warnMs`，1.4 秒）；攻擊落下時主角不在範圍內就會「閃開！」，沒有傷害。站在範圍內時，防禦仍然有效。

### 2.1 戰鬥的新樣貌

```
        怪物，巨大，在中間（有可以被打的點）
   ----------------------------------------------------------------
   每次攻擊前顯示危險範圍：近距離、一直線或半扇形
   ----------------------------------------------------------------
        [ 中 1 ]    [ 中 2 ]    [ 中 3 ]      主角站在六格之一，
        [ 後 1 ]    [ 後 2 ]    [ 後 3 ]      換格子來閃開
```

| 點子 | 意思 | 取代或使用什麼 |
|---|---|---|
| **六個格子** | 前後兩排，每排三格。主角在戰鬥中換格子 | 新的。目前主角站著不動 |
| **有形狀的攻擊** | 攻擊前，危險的格子會亮起：近距離、一直線或半扇形。攻擊有時間差，來得及移動 | 與防禦並存：玩家可移動或防禦（Q70） |
| **距離有差** | 有的怪近戰很痛、遠打很弱，所以站哪一排是個選擇 | 新的；放在每隻怪物的 `moves.json` |
| **怪物大小** | 小怪 20%、中怪 35%、大怪 50%、Boss 65%、特殊魔王 70% 以上 | 僅供參考；依方向調整到看起來合理（Q71） |
| **可被打的點** | 怪物有可以被打的點。弓箭打弱點才痛，打錯傷害低很多。有卡片就會提示 | 新的；每張怪物圖都要標記。文件 15 §3.5 與文件 17 §10 已規劃依武器的弱點 |
| **防禦教學** | 讓玩家知道不防禦被打幾下就掛了 | 文件 17 §11 的曲線也需要；教移動、防禦與魔王的畫圖防禦 |

### 2.2 每把武器的玩法

| 武器 | 攻擊前 | 攻擊 | 之後 | 可重用 |
|---|---|---|---|---|
| **弓** | 裝箭；等級越高裝越多 | **一次拉弓瞄準多個箭靶：** 瞄到的箭靶會暗掉，手放開或全部瞄到就射擊，一次射好幾發 | 打弱點才痛，其他傷害低很多 | 拉弓、多目標的 `TouchPlay`。**會改變文件 17 §7**（箭袋與齊射） |
| **魔杖** | 念咒：依序點球，特效要炫 | 滑到要打的地方，有提示 | 待在遠處安全 | 圓圈玩法（`sequenceClick`） |
| **劍** | **像彈珠一樣彈射到怪物前**，飛行中依序畫出指示的圖形 | 抵達後依畫出的成功率連砍 | **留在近處：連點每下只有 5% 攻擊力。** 離開才能再彈射與畫圖，有提示要滑回哪裡 | 11-05 做好的滑動難度（V、M、方形）與連擊動畫。要花時間才到：這是威力的代價 |

筆記也提到任何武器都是點任意點攻擊。這會是另一個新玩法，可能透過技能（§2.0）。

### 2.3 其他戰鬥點子

- **怪物對特定武器有加成：** 文件 17 §10 的抗性（W5）已涵蓋。
- **第四種武器：槍：** 用買的。文件 17 有三個系列，Q52 允許第四種傷害類型（Q73）。
- **大挑戰：** 每三次通關出現，同時考驗攻擊與防禦的大魔王。贏了給特殊寶物，輸了扣能力點（Q79）。

### 2.4 建議的順序

先在一隻怪物上測試好不好玩，再做內容。

| 步驟 | 內容 | 為什麼這個順序 |
|---|---|---|
| B1 | **您的示意圖：** 格子、攻擊形狀與三把武器（您的筆記） | 用圖確定格子 |
| B2 | **試玩戰鬥：** 苔蛙 50%、六格、三種攻擊形狀、時間差，武器不變 | 回答最重要的問題：移動閃避好不好玩？ |
| B3 | **魔杖**（念咒，然後滑動） | 最接近現有玩法 |
| B4 | **弓**（一次拉弓多個箭靶；弱點） | 需要在圖上標記點 |
| B5 | **劍**（彈射、畫圖、連砍、5% 連點、返回） | 改動最大 |
| B6 | **教學**、所有怪物的大小、每隻怪的距離特性 | 規則穩定之後 |
| B7 | **大挑戰魔王**、槍 | 需要上述全部 |

**對文件 17 的影響：** W5（抗性、切換）與 W6（對話欄）仍然適用。W4 的 12 種武器與 W7 的弓和魔杖玩法應該等一等，因為 B3–B5 會改變武器的玩法（Q74）。

**新遊戲教學（2026-11-06 已做，早於 B6）：** 武師的試玩戰鬥現在是對苔蛙（`thicketoad`）的教學，
設定在 `battle.json` 的 `tutorial`，文字在 `text.json` 的 `tutorial.*`。每一步的文字顯示在上方的框內，等玩家做到才繼續：

| 步驟 | 玩家要做到 | 同時 |
|---|---|---|
| 攻擊 | 攻擊兩次（弓射偏也算） | 苔蛙等待；格子隱藏；弓顯示虛擬手指 |
| 移動 | 攻擊落下時站在紅色格子外 | `toad_lesson_line`，閃開前會一直重複 |
| 防禦 | 在「!」出現時按防禦 | `toad_lesson_crush`，沒有格子，所以躲不開；防禦成功前會一直重複 |
| 收尾 | 打倒苔蛙 | 牠平常的招式，之後播放勝利動畫 |

苔蛙在任何一步都可能倒下，教學就會提早結束（擁有者，2026-11-06）；主角不會倒下：最低留 1 HP。換試其他武器時只重複「攻擊」與「收尾」（`once`）。
因此擁有者筆記中的「沒有防禦被打幾下就掛了」目前還沒有呈現。

**第一次危險的特寫（2026-11-06 已做）：** 一場戰鬥中怪物第一次點亮格子時，全部暫停 2.2 秒：畫面變暗、鏡頭拉近，只顯示怪物、牠的 `special` 動畫、粒子 `danger_intro` 與橫幅。1.2 秒後主角與其他介面回來，格子與教學文字框以縮放效果彈出，玩家有最後一秒閱讀，然後時間才繼續。在此之前格子都是隱藏的，每場戰鬥都一樣。設定在 `battle.json` 的 `cells.intro`。

## 5. 我會注意的地方

- **像三個不同的遊戲：** 格子戰鬥、塔內事件、領地建造都很吃力。您定的順序能把它們分開：測試第 1 部分不需要第 3 部分的任何東西。
- **大小與弱點的美術：** 佔畫面 50–70% 時，每隻怪物都需要繪圖與標記。目前只做了三隻。
- **防禦：** 移動、防禦與魔王的畫圖防禦都保留（Q70），所以畫面必須清楚顯示每次攻擊需要哪一種。
- **輸了扣點** 對一個設計成非常難的魔王可能太重（Q79）。
- **寫程式前要定的：** 您的示意圖。

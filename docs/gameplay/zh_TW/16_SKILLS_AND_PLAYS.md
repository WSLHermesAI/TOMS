# 16. 用可重複使用的元件做招式與玩法（擁有者的點子，2026-10-31）

擁有者 2026-10-31 的新點子，整理如下：三把武器玩法的重做、攻擊有節奏讓玩家應對的怪物、特殊防禦玩法、用卡片的練習場，以及像
魔杖五角星這樣的特殊招式。它接在戰鬥改版（[15](15_BATTLE_REVAMP.md)，已做到 R5）與 [14](14_WEAPON_PLAY_AND_LOOT.md) 的武器玩法之後。

**擁有者的主要要求：功能要能重複使用。** 一個特殊招式是資料：它的名字、它的數值、它自己的動畫。新的招式是檔案裡多一筆，而不是
新的程式碼。所以這份文件先說明**五個組成元件**（§2），再用它們組出每個點子（§3–§6）。

已於 2026-10-31 做進遊戲（§10；招式的檔案是 `special_moves.json`）。未決問題在 §9。

## 1. 擁有者的筆記（原文）

> 劍：每次可以攻擊每個方向會出現一秒鐘的提示，會有那種彈一下出現再消失的特效。劍每次方向都會攻擊一次。劍攻擊每次攻擊中的指定方向
> 攻擊只有1秒鐘沒輸入就是換下一個，這邊有的不會只有方向有的可能是三角形或是圓形，每次一秒鐘的等待但是只有0.5秒（可調整）可以輸入指令。
>
> 弓箭：靶會移動0.5秒然後在固定，並且瞄準越久抖動越大。弓箭需要教學，手指點任意地方反方向滑動，並且蓄力有秒數限制，越久震動越大但是
> 攻擊力也越強，會根據玩家的str決定可以拉多久，根據dex看會不會讓方向控制震動。普通拉弓就一下，招式才需要連續瞄準，並且要有particles的特效。
>
> 魔杖：數字順序會慢慢消失？快要可以點的時候會有驚嘆號0.5秒。魔杖每次點擊都會放魔法。魔杖不要有點一下才開始數數字，時間到就開始數，
> 並且數完就消失0.5秒然後在一起出現。
>
> 防禦：防禦的話會中斷玩家的攻擊，並且只有在怪物頭上出現驚嘆號時點才有效。有的怪物攻擊會0.5、0.5每隔固定時間攻擊，也有連續攻擊，
> 這邊要讓玩家決定要怎麼防禦或是攻擊。怪物需要設定攻擊的集氣以及攻擊次數跟每次攻擊的間隔。有的高級怪物不只要點防禦按鈕，還會進入
> 特殊防禦階段的遊玩，可能是畫五角星或是連點好幾下之類的。防禦有沒有進特殊遊玩是跟怪物綁定。
>
> 卡片：有卡片之後可以去特殊練習場直接指定怪物做連續攻擊好幾場的特殊升級玩法，讓收集怪物卡片變成能在練習場升級（每天有次數限制，
> 並且會消耗掉卡片數量）。
>
> 招式：玩家武器特殊招式，例如魔杖會出現一個事先做好的五角星動畫，先出現一個五角星然後particles會照五角星的繪畫方向邊移動邊噴出，
> 每到一個定點會做一個更誇張的爆炸特效，五個點都表演完，整體暗下倒數計時提醒玩家畫五角星，每完成一個頂點就一樣做一個爆炸特效並跑出
> 招式名字，例如super attack，每完成一個頂點螢幕會出現1/5的字，都集滿招式名都出現，玩家角色會播放對應的動畫來攻擊敵人，這邊先設定
> 大絕招會連續攻擊10下，或是拉近攝影機特寫玩家的特殊招式動畫，然後攻擊力是普通攻擊的N倍，先寫十之後可以調整。

## 2. 五個組成元件

每個元件是一份程式碼，設定放在資料裡。下面每個玩法、防禦與招式，都是這些元件用不同設定組成的。

| # | 元件 | 做什麼 | 設定（資料） | 用在 |
|---|---|---|---|---|
| B1 | **提示序列** | 一個接一個的提示。每個提示彈出（短暫彈跳）、等待，並開一個**輸入時間窗**；時間內沒輸入就換下一個。每個答對的提示可以立刻命中 | 每個提示：要做什麼（方向、圖形、點擊、位置）；`cueMs`（1000）、`inputMs`（500）、時間窗在提示中的位置、彈出特效 | 劍、魔杖、怪物攻擊、特殊防禦、招式 |
| B2 | **手勢** | 讀手指：點擊、滑動與方向、往後拉再放開（拉弓）、按住、連點（次數），以及**畫出的圖形**：依序經過它的頂點（三角形、圓、五角星） | 每個圖形：頂點（0 到 1 的點）、順序、要多接近頂點；滑動的容許誤差；拉弓的限制 | 所有玩法 |
| B3 | **提示驚嘆號** | 在怪物或某個位置上方出現「!」，在可以應對之前 `warnMs`（500）。只有**在它出現時**的應對才算 | `warnMs`、驚嘆號的外觀（圖片或特效） | 防禦、魔杖、怪物攻擊 |
| B4 | **演出** | 有時間的視覺節拍清單，招式的示範與收尾都一樣。每個節拍：播放粒子特效（也可以沿路徑邊走邊噴）、在某點爆炸、角色動畫片段、橫幅或文字、畫面變暗、倒數、攝影機特寫、震動 | 每個節拍：時間、種類、它的檔案（`battle.particle`、`.anim` 片段）、數值 | 招式、絕招、特殊防禦 |
| B5 | **招式** | **`special_moves.json` 裡的一筆**：名字、玩法（B1 + B2）、演出（B4）、每一步的回饋、收尾（攻擊次數、傷害倍率）。玩家的招式、武器的絕招、怪物的特殊防禦都是招式 | 見 §6.2 | 所有有名字的東西 |

以魔杖的五角星（§6.1）為例，它們這樣組合：

```
招式「星之印」 ──► 演出 "demo"   （B4：粒子畫出五角星，每個頂點一次爆炸）
              ──► 玩法          （B2 圖形 "pentagram"，依序 5 個頂點，在倒數之內）
                    每個頂點 ──► 演出 "step"  （B4：爆炸、「1/5」、招式名的下一段）
              ──► 演出 "finish" （B4：變暗、特寫、角色的動畫片段、連擊 10 下）
              ──► 傷害          （普通攻擊 × 10，分到 10 下）
```

現在已有、可以重複使用的：提示與命中粒子（`battle.particle`、`playBattleFx`）、節點效果
（[../../engine/zh_TW/18_NODE_EFFECTS.md](../../engine/zh_TW/18_NODE_EFFECTS.md)）、武器拿在手上的角色片段（CharacterRig，例如
`attack_big`）、橫幅、頓幀、震動與畫面變暗（15，R1/R4）、觸控玩法（`touch_play.h`，R5）。**新的：** 提示序列（B1）、畫出的圖形
（B2）、提示驚嘆號（B3）、以資料描述的演出時間軸（B4）、`special_moves.json`（B5），以及戰鬥攝影機特寫。

## 3. 武器玩法重做

| | 目前已做（15 R5） | 新點子 |
|---|---|---|
| 劍 | 所有箭頭一起顯示；最後一刀後才有一個結果 | **提示序列**：一次一個提示，每個各自命中 |
| 弓 | 每支箭一個固定的靶；拉的長度決定瞄準 | 靶**移動 0.5 秒後停住**；拉弓**蓄力**（越久越強也越晃）；普通攻擊拉一次 |
| 魔杖 | 點一下開始節拍；有編號的圓圈依序收合 | **自動開始**；數字依序數、隱藏，然後圓圈一起回來；每個之前有「!」；每次點擊放魔法 |

### 3.1 劍：每個提示砍一刀

- **提示序列**（B1）。每個提示在怪物上方彈出，停 **1 秒**（`cueMs`）。其中只有 **0.5 秒**（`inputMs`，可調）接受輸入。沒輸入：
  它過去，下一個提示出現。
- 一開始提示是**方向**（8 種之一）。之後的提示可以是**圖形**：三角形、圓（B2）。
- **每答對一個提示就立刻命中一次**，有自己的數字與特效。提示用完時攻擊結束。
- 武器等級決定提示數量，以及會出現哪些種類（Lv 1 只有方向，之後有圖形）。

### 3.2 弓：瞄準、拉弓、放開

- **靶**出現時移動 **0.5 秒**，然後停住不動。
- **拉弓**（B2）：點**任何地方**往反方向拉（彈弓），然後放開。準心往拉的反方向，跟現在一樣。
- **蓄力：** 拉得越久射得越強，有上限。兩個屬性決定：
  - **STR** 決定能拉多久（蓄力上限）。超過時，箭自己射出，或蓄力往下掉（Q41）。
  - **DEX** 決定瞄準晃動多少。瞄越久晃越大；DEX 高就晃得小。
- **普通攻擊是拉一次、射一箭。** 只有**招式**才需要連續瞄準好幾次，每支箭都有粒子特效。
- **教學**：第一次用弓攻擊時，一隻虛影手指示範「點、往後拉、放開」（每個存檔一次，設定裡可以再看）。

### 3.3 魔杖：數數、隱藏、照順序點

依擁有者筆記的理解（Q40 確認）：
1. 攻擊準備好時玩法**自動開始**（不用點一下開始）。
2. 圓圈**帶著數字**出現，並**依序數**：1、2、3……，一個一個亮。
3. 數完時，它們**全部隱藏 0.5 秒**，然後**一起回來**，不帶數字。
4. 玩家**照記住的順序**點它們。每個圓圈可以點之前 **0.5 秒會出現「!」**（B3）。
5. **每次點擊立刻放一個魔法**（命中一次，特效從圓圈飛向怪物）。

用元件組成：提示序列（B1）的提示是位置，每個有提示驚嘆號（B3），點擊（B2），以及數數與隱藏的演出（B4）。

## 4. 怪物：玩家應對的攻擊節奏

### 4.1 一次攻擊是集氣，然後隔著間隔的幾下

現在怪物的招式（`moves.json`）有前搖（`time`），連擊有 `hits`。新點子讓每次攻擊都有玩家看得懂的節奏：

| 設定 | 意思 | 例子 |
|---|---|---|
| `chargeMs` | 它的集氣（期間顯示它的意圖） | 1500 |
| `hits` | 打幾下 | 3 |
| `gapsMs` | 每下之前的時間（一個值，或每個間隔一個值） | `[500, 500]`：穩定；`[150, 150, 600]`：快速連打，再一下晚的 |
| `warnMs` | 每下之前頭上的「!」（B3） | 500 |
| `guardPlay` | 一個招式 id：用特殊防禦玩法取代按鈕（§4.3） | `"guard_pentagram"` |

```json
"triple_bite": { "kind": "jabs", "damage": 0.5, "chargeMs": 1500, "hits": 3, "gapsMs": [500, 500], "warnMs": 500 },
"frenzy":      { "kind": "jabs", "damage": 0.3, "chargeMs": 1200, "hits": 5, "gapsMs": [150, 150, 150, 600] },
"doom_seal":   { "kind": "spell", "damage": 2.5, "chargeMs": 2500, "hits": 1, "guardPlay": "guard_pentagram" }
```

這是怪物那一邊的提示序列（B1）：每一下是一個帶驚嘆號的提示。玩家自己選：每下都防禦，或在長的間隔中攻擊並吃一下。

### 4.2 防禦

- **只有怪物頭上出現「!」時防禦才算**（B3）。早或晚都是沒擋到。
- **防禦會中斷玩家自己的攻擊**（正在進行的玩法停止，就像怪物的連擊已經會中斷它）。所以防禦有代價，選攻擊還是防禦才有意義。
- 15 §3.2 的招架／擋下等級可以留在「!」的時間窗裡（前段是招架，其餘是擋下），或「!」只有單一的「擋下」（Q42）。

### 4.3 特殊防禦玩法

- 有些強的怪物的攻擊，要求**一個玩法**而不是防禦按鈕：畫五角星、快速點 N 下、照顯示的方向滑。
- **它屬於怪物的招式**（`guardPlay`，一個招式 id）。同一個招式可以給好幾隻怪物用。
- 結果決定傷害：全部完成 = 沒有傷害（也許讓牠硬直）；完成一部分 = 受到一部分傷害。

## 5. 練習場：讓你升級的卡片

- 從卡片收藏，玩家**選一隻**自己有卡片的**怪物**，**連續**跟牠打**好幾場**（一輪連戰，像武器競技場那樣）。
- 這是**特殊的升級方式**：勝利給經驗與武器的使用次數（等級），也許比平常多。
- **每天有次數限制**，而且**每輪會消耗**那隻怪物的卡片。
- 它重複使用競技場（07 階段 0）做連戰，以及卡片收藏（07 §3、14 §3）作為代價。
- **這改變了之前的決定。** 擁有者在 2026-10-20 說卡片目前只是收藏；消耗卡片是新的（Q44）。

## 6. 特殊招式：資料，各有自己的演出

### 6.1 魔杖的五角星，一步一步

| 步驟 | 發生什麼 | 元件 |
|---|---|---|
| 1 示範 | 出現一個五角星。粒子**照繪畫順序沿著線移動**，邊走邊噴 | B4（路徑特效） |
| 2 | 在**每個頂點**一個更大的爆炸 | B4 |
| 3 | 第 5 個頂點之後，畫面**變暗**並開始**倒數**：「畫出五角星」 | B4 |
| 4 玩法 | 玩家畫。**每依序到達一個頂點**，就有一個爆炸、**「1/5」……「5/5」**，以及招式名的下一段（「SUPER ATTACK」一段一段出現） | B2 圖形，每步 B4 |
| 5 收尾 | 五個都完成：整個名字出現；角色**播放這個招式自己的片段**，加上**攝影機特寫**；**連續 10 下** | B4 |
| 6 傷害 | **普通攻擊 × N**（先設 N = 10，放在資料），分給每一下。頂點較少：較少 | B5 |

倒數結束時：已完成的頂點算數（3/5 → 傷害的 3/10，或較弱的收尾；Q45）。

### 6.2 同一件事寫成資料（`special_moves.json`）

```json
"star_seal": {
  "name": "skill.star_seal",                 "_": "text.json 的 key：招式名，每種語言",
  "weapon": "staff", "use": "ultimate",      "_use": "ultimate（絕招能量滿）、skill（技能清單）、guard（怪物的 guardPlay）",
  "play": { "gesture": "shape", "shape": "pentagram", "timeMs": 6000, "cornerRadius": 40 },
  "demo":   [ { "at": 0,    "do": "pathFx", "shape": "pentagram", "fx": "star_trail", "ms": 2000 },
              { "at": "corner", "do": "fx", "fx": "star_burst" },
              { "at": 2200, "do": "dim", "value": 0.6 }, { "at": 2200, "do": "countdown" } ],
  "step":   [ { "do": "fx", "fx": "star_burst_big" }, { "do": "count" }, { "do": "namePart" } ],
  "finish": [ { "do": "name" }, { "do": "camera", "zoom": 1.6, "on": "player", "ms": 1500 },
              { "do": "clip", "clip": "ultimate_star" }, { "do": "hits", "count": 10, "gapMs": 120 } ],
  "damage": 10
}
```

**另一個招式就是另一筆。** 同樣的元件、不同的數值、自己的動畫：

| 招式 | 武器 | 玩法 | 演出 | 收尾 |
|---|---|---|---|---|
| 星之印 | 魔杖 | 畫五角星 | 粒子沿著星形 | 10 下，×10 |
| 虎虎生風 | 劍 | 提示序列：4 個方向，再一個三角形 | 每刀一個斬擊特效 | `attack_big` 片段，4 下，×4 |
| 鷹之雨 | 弓 | 連續瞄準 3 個移動的靶 | 每箭一條箭痕 | 箭從天而降，6 下，×5 |
| 五角星防禦 | （怪物的） | 在牠的倒數前畫出五角星 | 怪物的封印發光 | 5 個都完成：沒有傷害 |
| 連打防禦 | （怪物的） | 2 秒內點 12 下 | 盾牌碎裂 | 傷害 × (1 − 點擊數 / 12) |

戰鬥編輯器（[13](13_BATTLE_EDITOR.md)）新增一個 **招式** 分頁來製作與試玩它們，像怪物與武器分頁一樣；招式的動畫在動畫編輯器做、
特效在粒子編輯器做，然後在這裡指定名字。

## 7. 現有的東西會怎麼變

| 現在 | 變成 |

| 沒有戰鬥攝影機 | 特寫某個戰鬥者（縮放與移動，緩動回來） |

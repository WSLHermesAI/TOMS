## 2. 每種武器有自己的玩法

目前弓、劍、杖共用一種玩法：軌道上的點，在時機點擊（07 第 13 節，`combo_play.h`），各自的設定在 `weapon_play.json`。
以下想法讓每種武器有自己的玩法。用語對應遊戲裡已有的東西：

| 負責人的用語 | 遊戲中                       | 目前的位置                                       |
| ------------ | ---------------------------- | ------------------------------------------------ |
| 等級         | 武器等級                     | `weapon_play.json` 的等級（07 第 13 節）       |
| 技能         | 玩家解鎖、在戰鬥中使用的技能 | 技能系統（`skill_system`），例如「Qi Drawing」 |
| 絕招         | 必殺技，必殺能量滿時使用     | 必殺能量條（5 格）                               |
| 會心         | 最好的結果，會心招式         | 「perfect」結果列（13 第 4.2、10 節）            |

### 2.1 弓：拉弓射中目標

- **玩法：** 畫面上一個方塊代表弓。玩家往後拉（按住拖曳），放開就射向目標。
- **依等級與技能：**
  | 何時   | 每次射出                       |
  | ------ | ------------------------------ |
  | 等級低 | 一箭                           |
  | 用技能 | 兩箭                           |
  | 絕招   | 靶出現在不同地方，每個靶射一箭 |
- **會心：** 絕招的靶全部射中，就出會心招式（弓的 `attack_big` 齊射，13 第 10 節，可當第一版的樣子）。
- 與 07 第 5.5 節弓的提案（準星在敵人身上擺動）相比：拉弓保留，擺動的準星改成要射中的靶。

### 2.2 劍：一刀兩斷

- **玩法：** 類似切水果遊戲：玩家劃過敵人，每劃一次就是一刀（一刀兩斷）。
- **依等級：**
  | 何時     | 刀數             |
  | -------- | ---------------- |
  | 等級 1   | 一刀             |
  | 等級提升 | 每次攻擊可砍多刀 |
  | 絕招     | 要照指定的方向砍 |
- **絕招之後的連招考記憶跟方向：** 先顯示一串方向，然後隱藏，玩家憑記憶劃出來。
- 與 07 第 5.2 節（多邊形的點、沒有第二次機會）相比：用劃取代點擊，「沒有第二次機會」可保留（方向錯就斷連）。

### 2.3 魔法杖：抓時間點的圈圈，再畫魔法陣

- **玩法：** 類似應援團，與 07 第 5.3 節的規劃相同：圈圈出現，在時機點擊。
- **依等級：**
  | 何時   | 出現什麼                                                                   |
  | ------ | -------------------------------------------------------------------------- |
  | 等級低 | 1–2 個圈圈                                                                |
  | 等級高 | 很多圈圈、節奏很快，要在指定的地方、指定的時間點擊，還要**畫魔法陣** |
- **畫魔法陣：** 玩家描畫畫面上顯示的圖形（圓、星、符印）。準確度與速度就是威力。（07 第 5.5 節把畫圖形給了戰鎚，見 Q30。）

### 2.4 三者共通

- 所有玩法用同一個結果等級：miss、hit、great、perfect／會心，所以 `weapon_play.json` 的 `results`（13 第 4.2 節）
  與為它們做的美術（13 第 10 節）都能繼續用。
- 等級、技能、絕招改變的是要做*多少*（箭數、刀數、圈數），不改規則，新玩家每種武器只要學一次。
- 每種玩法是 `combo_play.h` 旁邊的獨立模組（例如 `bow_play`、`slice_play`、`circle_play`），由武器在
  `weapon_play.json` 的設定選擇（`"play": "bow"`），戰鬥編輯器（[13](13_BATTLE_EDITOR.md)）就能試玩。
- 三種都要能在橫向與直向、觸控與滑鼠下玩（[12](12_UI_LAYOUT.md)）。

### 2.5 雙手劍：記住方向（負責人，2026-11-04）

這是想法，尚未製作。分兩個階段：

1. **顯示：** 連續出現 N 個方向提示，每個顯示 X 秒（預設 0.3）。
2. **回答：** 玩家有 N × X 秒。畫面只顯示現在是第幾招（1、2、3……N），沒有方向，玩家要憑記憶滑出方向。

每答對一個就會攻擊敵人，每完成一個指令，攻擊力乘上一個倍數：

| 指令              | 1   | 2   | 3   | 4   | ……      |
| ----------------- | --- | --- | --- | --- | --------- |
| 攻擊力 ×（預設） | 1.2 | 1.4 | 1.6 | 1.8 | 每段 +0.2 |

倍數可調整。以預設值來說，N = 3 時顯示方向 0.9 秒，回答時間 0.9 秒。

負責人較短的筆記寫三個提示、每個 0.3 秒、一秒內畫完。它符合 N = 3、X = 0.3，但回答時間是 1 秒，也沒有說方向會隱藏（Q63）。

這與 [17](17_WEAPONS_AND_PLAYS.md) 第 3 節（雙手劍從 V 形滑動開始）以及第 2.2 節劍的連招不同。尚未決定的細節是 Q59–Q63
（第 5 節與 [../../project/zh_TW/13_OPEN_DECISIONS.md](../../project/zh_TW/13_OPEN_DECISIONS.md)）。

## 3. 刷怪打寶：刷怪、開寶箱

無聊時打開的模式：一隻接一隻打怪，收集掉落物，開寶箱拿裝備，一直往更深處去（Diablo 式的刷寶）。

### 3.1 循環

```
 打怪 ──► 收集掉落物（寶箱鑰匙／代幣） ──► 開寶箱 ──► 更好的裝備 ──► 往更深處
   ▲                                                                  │
   └──────────────────────────────────────────────────────────────────┘
```

1. **打怪：** 怪物一群接一群出現；每場都是一般戰鬥，用玩家的武器玩法。
2. **收集：** 打倒的怪物掉落可以累積用來開寶箱的東西（貨幣或鑰匙；Q32）。
3. **開寶箱：** 用收集到的東西開寶箱，隨機得到裝備與道具。
4. **特殊怪物：** 只有特定怪物會掉**指定寶箱**，裡面有**特別道具**（有名字的武器、稀有裝備）。它們是狩獵的目標。
5. **更深處：** 每往下一層，怪物更強、寶箱更好。目標是盡量往深處去。
6. **裝備：** 裝上找到的東西會有能力加成（六項能力，[11](11_BATTLE_DATA.md)）；「整裝」也可能是指穿齊一整套的套裝加成（Q33）。

### 3.2 與現有系統的關係

- 它是**其他模式**之一（07 第 8 節）：屬於 TOMS，但是獨立模組，只透過開始、結果、玩家能力與裝備和遊戲溝通。
- 07 第 8 節的放置型橫向捲軸可以是它的樣子：主角一直往前走，怪物出現，沒下指令時主角依能力自動戰鬥（Q31）。
- 沿用戰鬥（Battle v3、第 2 節的武器玩法）、卡片（每次擊倒都算進該怪物的卡片，07 第 3 節）、貨幣（金幣、水晶，
  07 第 16 節），以及 `items.json`／`equipment.json` 的裝備。
- 寶箱內容是資料：每個寶箱、每隻特殊怪物一份掉落表（在 `enemies.json` 或新的 `chests.json`），戰鬥編輯器可以調整。

## 4. 建議的順序

1. 回答第 5 節的問題。
2. **先做一種武器玩法：弓**（第 2.1 節）：弓是起始武器，每位玩家都會看到。做在現有玩法旁邊，用 `weapon_play.json`
   的 `"play"` 切換，再到戰鬥編輯器試玩。
3. 劍的劈砍（第 2.2 節），再來是杖的圈圈與魔法陣（第 2.3 節）。
4. 刷怪打寶（第 3 節）：先做一層、一種寶箱的循環，再加特殊怪物、深度與套裝加成。

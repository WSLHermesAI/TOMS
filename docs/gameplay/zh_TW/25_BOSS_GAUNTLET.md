# 25. 頭目戰改成連戰（2026-11-22）

擁有者（2026-11-22，附一張圖：三個方塊、向下的箭頭，然後「BOSS a ? picture」）：三隻怪物組隊一起打，對一般怪物是對的，但頭目戰不是。
頭目戰應該是**連戰**：先打一隻怪物；贏了，3D 場景移到下一隻怪物的位置；再贏，再往前；全部打倒後頭目出現。途中有一個**直向的列表**顯示
要打幾場：每格都是黑的，直到打到那隻怪物時才顯示牠的圖。

**已做好（§4）。**未決的問題在 §5 與 [13_OPEN_DECISIONS.md](../../project/zh_TW/13_OPEN_DECISIONS.md)。

## 1. 什麼時候

- 在地圖上撞到**頭目**（enemies.json `"intro": true`：樓層頭目、灰面、沃卡司）就開始連戰。一般怪物的 `"party"` 仍和牠一起同時打，
  和以前一樣。
- **守衛**依這個順序決定：關卡物件的 `"gauntlet"`（怪物 id 清單），否則頭目在 enemies.json 的 `"gauntlet"`，否則牠的 `"party"`
  （不再和頭目一起打），否則樓層裡其他怪物最多 `count`（3）種，每種一次，依地圖順序（battle.json `"gauntlet"` `"fromFloor"`）。
  沒有守衛：只打頭目，和以前一樣。F01 的蜂熊：小帽菇、苔蘚怪、蝙蝠，然後是牠。

## 2. 戰鬥

- **每個守衛是一場單獨的戰鬥**，一隻怪物；贏了和一般勝利一樣有報酬（金幣、經驗、武器經驗、卡片），但**不顯示結算畫面**（擁有者，
  2026-11-22）：報酬以通知顯示（「+6 金幣・+7 經驗」），下一場立刻開始。
- **下一場**：主角回到待機姿勢（不是勝利姿勢），3D 舞台**前進**到下一隻怪物的位置（battle.json `"gauntlet"` `"step"`：每場
  [0, 0, -3.5] 公尺，往舞台裡面；`"travelMs"` 1500）：主角與鏡頭走向在自己位置等待的怪物；移動時一切等待。
  主角**跑**過去（2026-11-23）：每步一次彈跳、身體前傾、腳下一團塵土（`"run"`）。**必殺充能**在場與場之間保留，不會歸零。
- **後面的怪物站在遠處**（Q126，擁有者：「show them in the distance」）：各在路上自己的位置，稍微偏向一側（左右交替，`waitingSide`
  0.9 公尺），是黑色的剪影（`waitingShade`、`waitingAlpha`）：打到時才知道是誰，和列表一樣。
- **頭目**是最後一場。牠先**從黑暗中出現**（擁有者，2026-11-23：「先半黑，再變成彩色，然後是洛克人的效果」）：等待時是暗的（bossIntro
  `"dark"` 0.97，在自己上面再畫一次黑色），在 `"revealMs"` 1400 內恢復顏色，然後和以前一樣登場（頭目橫幅）；任何有登場的頭目都這樣，
  不論是否連戰；牠的勝利顯示結算畫面；打贏會清掉牠的格子，樓層頭目會打開上樓的樓梯。
- **輸了**連戰就結束：頭目留在格子上；下次從第一個守衛重新開始。場與場之間扣掉的 HP 不會回復（守衛就是考驗）。
- 沒有 3D 舞台（設定 > 3D 戰鬥：關）時一樣一場接一場，只是沒有前進的移動。

## 3. 列表（battle.rml `#gauntlet`）

在戰鬥畫面左側往下，一場一格，頭目的在最下面（較大、較圓、紅框）：

| 狀態 | 格子 |
|---|---|
| 還沒打到 | 黑色：怪物的圖是黑的，「?」（頭目：「頭目 ？」/ "BOSS ?"） |
| 正在打 | 牠的圖，金框（頭目：紅框） |
| 已打贏 | 牠的圖，變暗，名字是綠色 |

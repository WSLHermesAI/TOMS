# 23. 故事與事件改造：爬上高塔的孤兒（2026-11-20）

擁有者（2026-11-20）：戰鬥是「10 分中的 6 分」，故事與事件是「1 分」。大部分事件只是打招呼，沒有事可做。遊戲需要真正的 RPG 感：
有趣的故事、要拯救的人、要復仇的理由、值得玩的事件。擁有者請我找出 [rpg_story_concept_book.html](../rpg_story_concept_book.html)
中哪個提案最接近目前的遊戲，並選定了下面的方向。**這是計畫；S1（工具）、第 1–3 章（第 4.1–4.3 節）已做好，第 4–7 章尚未製作。** 未決的問題在第 9 節與
[13_OPEN_DECISIONS.md](../../project/zh_TW/13_OPEN_DECISIONS.md)。

## 3. 故事

**前提。** 一個孤兒少年（暫名 **里歐**，Q110）和撫養他的農夫夫婦過著幸福的日子。某夜，戴面具的士兵——**收集者**——燒了村莊，
把他的父母和半村的人帶上**巫師之塔**。他們的隊長（暫名 **灰面**，Q111）說：*「找到那個孩子。預言說他是最後的鑰匙。」*
里歐在倒下的怪物之間醒來：他體內有什麼甦醒了。他攀上高塔，要把家人帶回家，也要讓燒掉村莊的人付出代價。

**轉折，一步步揭開。** 他的父母知道他是 **神裔** 的最後血脈——一個能吸收被擊敗生物力量的古老種族——並把他藏起來，讓他能有平凡的
童年。收集者為統治塔頂的人收集有天賦的孩子。巫師王 **沃卡司**（沿用目前的設定）並不是村民以為的那樣：他封印**安穩之星**，是為了
擋住更可怕的東西——一個想要神裔之身的古神。被囚在塔頂的莉歐拉，握著那道封印的鑰匙。

**調性。** 主線真誠（家人、失去、復仇或寬恕）。喜劇來自角色、支線與怪物，從不嘲弄主線。情感的回報——他找到母親時：
*「我們從來不希望你成為神。我們只希望你有個快樂的童年。」*

**主題。** 家人由愛而非血緣構成。力量不決定一個人的價值。英雄就是選擇要保護誰——即使是你原本要復仇的人。

## 5. 有內容的事件

**目標：每一層至少有一個真正的事件，沒有只打招呼的 NPC**（計畫的目標，不是專案規則：擁有者，Q112）。 六種事件取代純文字事件：

| 種類 | 會發生什麼 | 例子 |
|---|---|---|
| **救援**（讓村莊成長） | 樓層上的俘虜：救出他們（打倒看守、找到鑰匙、一段小玩法）；他們回到村莊並開放某樣東西 | F03 救出麵包師 → 村莊麵包店（戰前回血的食物） |

| **選擇**（有後果） | 放過或戰鬥、給予或留下、信任與否；改變之後的事件、同伴與結局 | F07 放過一名飢餓的收集者士兵：第 5 章軍營埋伏前他會警告你 |
| **劇情場景** | 樓層上的短場景：反派、線索、莉歐拉的聲音、與父母的回憶 | 灰面在 F05 的樓梯上看著你 |
| **喜劇支線** | 反覆出現的荒謬委託 | 皮普的「投資機會」；想當騎士的史萊姆；只跟著肚子餓的人走的雞 |
| **談話 N 次**（擁有者，2026-11-20） | 反覆和同一個 NPC 說話：第 N 次時給你特別的東西——**能開門的鑰匙**或**特別的武器**（對話系統已經會計算次數：`talkCountAtLeast`，也能給予：`give`） | F02 害羞的牧羊女：第 5 次談話時給你舊果園大門的鑰匙 |

**村莊成長。** 村莊一開始被燒毀、幾乎沒人。每個被救的村民回家後開放一項服務或任務：麵包師（食物）、治療師（回復）、鐵匠（鍛造）、
皮普（商店）、製圖師（樓層地圖）、旅店老闆（休息、信件）、算命師（提示）、吟遊詩人（音樂室）。玩家越往上爬，村莊就越熱鬧：
每次救援的回報看得見，而不只是數字。

**每章需要的內容（檢查清單）：** 5 層、至少 5 個真正的事件、1–2 次救援、1 個任務、1 個選擇、1 個喜劇支線、頭目前後各有場景，
以及每個遇到的 NPC 都有隨劇情改變的台詞。

## 6. 選擇與結局

三個新的計數（故事資料已支援計數，`story/counters.json`；目前的是 `humanity`、`insight` 等）：**寬恕**（放過、原諒）、
**復仇**（懲罰、奪回）、**信任**（凱與莉歐拉的信任）。第 5 章的重大選擇（灰面）與第 7 章的最後選擇，加上這些計數，決定結局：

| 結局 | 大致上 |
|---|---|
| **回家**（好結局） | 救回家人、放過灰面或將他繩之以法、信任莉歐拉：安穩之星重啟、村莊重建 |
| **復仇者**（苦甜） | 救回家人、盛怒之下殺了灰面：村莊得救，少年卻變了 |
| **神**（黑暗） | 選擇力量而非家人：成為古神的身體 |
| **隱藏** | 救出所有人、完成所有支線 |

目前故事的轉生循環不在這個計畫內（Q114）。

**S1，已做好（2026-11-20）：**
- 對話與事件動作（`story_actions.h`）：**`rescue`** `{npc}`（跑團旗標 `home.<npc>`、通知「{name}回到村莊了！」、等待它的任務）；**`startDialogue`** `{dialogue}`（樓層場景開啟一段對話）；**`openStore`**；**`heal`** `{cost}`。
- **任務**（`missions.json`、`mission_system.h`）：**`flag`** 目標（跑團或故事旗標被設定：救援的 `home.<npc>`、選擇的旗標）；接下時旗標已設定的任務立刻完成；接下、達成（「回去回報吧」）與領取時有通知並顯示標題；**隨存檔保存**（`RunSaveData::m_jMissions`）。
- **村莊成長**：`hub.json` 中 `unlockFlag` 為 `home.<npc>` 的地點，在該村民回家後開放（第一個：`hub_bakery`，麵包師）。
- `events/kinds.json` 中的**事件種類**：任務、抉擇、劇情、喜劇支線、談話 N 次（救援原本就有）。
- 範例任務 `m_rescue_baker`（長老：把麵包師帶回家；20 金幣、10 經驗）。
- 測試：`scenario.story_rescue_quest`（接任務、救出麵包師、任務達成、領取、治療：金幣 0 → 15）、`scenario.story_village_bakery`（有 `home.baker` 時麵包店開放）；`unit.save_test` 加了任務存讀檢查（已關閉，沒跑）。
- 還沒做：任務日誌自己的頁面（任務和以前的 missions 一樣顯示在事件分頁）、有頭像的村莊畫面（村莊仍是選單清單）、場景立繪。

每一步：先寫英文與繁體中文（其他語言在每章之後），為救援、任務與選擇寫情境測試，並在下一步之前由擁有者試玩。

# 17. 武器系列、遊玩型態、抗性與戰鬥對話（擁有者的點子，2026-10-31 晚上）

擁有者玩過 [15](15_BATTLE_REVAMP.md) 與 [16](16_SKILLS_AND_PLAYS.md) 的戰鬥後的筆記：發現的問題，以及更大的計畫。簡單說：
- 武器分成**系列**，各有自己的等級與能力；
- 每一種攻擊的玩法都是清單中的一種**遊玩型態**，由資料設定；
- 弓有**彈藥**，法杖要**集氣**；
- 怪物有**抗性與弱點**，玩家在戰鬥中**切換武器**；
- 一個**戰鬥對話欄**評論戰況；
- 更大的**戰鬥畫面**、**背景**，以及**難度曲線**。

它改變了 16 的一些答案（§13）。目前已完成：語言（§16）。擁有者已於 2026-11-02 回答 Q47–Q56（§16）；新的問題在 §18（Q64–Q67 於 2026-11-04 新增）。

## 1. 擁有者的筆記（原文）

> 動畫跟攻擊沒對上、每點一下要播一個攻擊的動畫。劍的三角形跟圈圈都不對，要簡化。要多個0.幾秒不然有點難。事件scroller不能工作（選單中的事件）。
> 圈圈沒很難用出來三角形失敗率超高、Dex可以增加判別成功率。道具或是裝備要顯示劍的能力、能幾連招、還有多久升級。
> 商店買了武器沒出現在道具欄跟不能裝備。敵人會四處走動。怪物的平衡要調整。戰鬥速度可以調整。
> 做個海洋跟skybox當背景、天空當背景、火山爆發當背景。
>
> 劍的絕招，任意方向滑動都算成功沒有等待時間，持續三秒。弓箭絕招，任意地方滑動必定命中沒有等待時間兩秒。魔杖絕招，任意地方連點都算成功沒有等待時間兩秒。
> 劍的普通攻擊增加打勾，兩個方向的連續滑動。
>
> 弓箭：需要拿弓箭放到箭袋才能射擊（點擊弓箭圖案），根據等級提升一次裝備的弓箭數量也不同，沒有弓箭要補弓箭，跟fps射擊遊戲一樣，沒有子彈要填彈才能射擊。
> 然後可以一次裝好幾個箭射出，要做一個左右滑動增加弓箭數量，弓箭等級提升才能裝更多的弓箭一次射出。一個是上子彈的概念，一個是一次射出好幾發子彈提高攻擊力跟命中率的概念，
> 這兩個有點難解釋，需要做出畫面上的提示讓玩家知道。
>
> 某些怪物怕遠攻某些怕近戰，有的怕魔法，所以玩家戰鬥中可以切換武器，要達到第二章後遇到武器商人才能買入，這時候跳個通知讓玩家知道戰鬥中可以切換武器，戰鬥畫面新增可切換的圖示。
>
> 魔杖普通需要做一個集氣才能攻擊的點擊，集氣越久攻擊力越強，但是集氣時間跟技能有關，而且集氣可以點招式要畫出指定集氣方法（類似畫五芒星的操作），不同的集氣會引起點擊時有不同的忽快忽慢節奏，甚至是連點好幾下的操作。
>
> 這邊設定武器是可以買，不同武器有不同的特別招式，吃設定檔。然後玩家的武器熟練度能使用不同武器都可以用的招式，所以寫程式的時候要做一個enum(列舉）eDRAW_SHAPE, eSEQUENCE_CLICK....
> 所有的戰鬥遊玩判斷型態要列舉，並且手滑動指定形狀，滑動分向，連點幾下等類型都可以直接吃指定的設定檔以及對應的動畫或是參數，例如畫形狀會吃position and time，anim editor 中的動畫格式，
> 畫面會先表演一次兩倍速的動畫，然後會出現第一個點發亮提示並且出現一條線指示玩家要怎麼滑動到第二個點，依此類推依照檔案的設定來畫出指定圖案，並且會播放每個點成功或失敗音效及動畫，有的招式可允許失敗有的不允許（可設定）。
> 目前想到的有不同武器的普通攻擊需要不同的操作方式來攻擊。例如一開始的劍，弓箭，魔杖不需要特別的前置動作，攻擊時也沒有特別的指令，依照目前玩法即可。
> 但是換武器後：比較重的劍需要蓄力N秒才能攻擊，蓄力時要有動畫或是特效；雙手劍不能防禦，等待時間較短，但是滑動起跳是兩個方向，適合想快攻的人。
> 劍跟弓箭跟魔杖用上面給的例子麻煩在各產生三種前置以及攻擊時稍微不同的特殊操作，並且在武器說明會寫出遊玩方法，戰鬥場景時也有明顯的提示讓玩家知道怎麼操作。
>
> 每個武器熟練度方面基本都有5招可在戰鬥場景中選擇使用，然後每種武器各有四種不同型態的類型，例如劍的話有長劍，雙手劍，重劍，短劍，然後每種劍有自己的等級，這邊更正一下前面講到的武器特別招式，
> 武器沒有特別招式但是有特別的能力對應劍的等級，例如雙手劍等級提升會降低等待時間以及滑動方向的難易度會降低，可能前面五級都是降低等待時間5%，後面是降低滑動方向的難易度，例如本來是一個打勾兩個方向但是會直接變成一個打勾就好，
> 這邊要先定義好滑動方向的資料有哪些，例如8個方向的滑動是難易度一，任意方向打勾（V)的滑動是難易度二，任意方向M字型滑動是等級三，四點中任意點啟動的四方型滑動等級四。
> 請以此架構撰寫魔杖跟弓的遊玩方法，主要用意是讓玩家除了基本武器招式可以用並且要搭配武器的特殊能力來增加遊戲遊玩的思考，有的怪物不怕魔法有的不怕物理，有的要用弓箭，怪獸的說明可以標記，
> 例如石頭怪不怕物理攻擊，這時候對劍的抗性是50%所以玩家要自己看打下去不痛要自己換武器，打倒怪物後，卡片也會寫，所以這邊怪物要多一個抗性跟弱點特性，普通小怪都是沒抗性跟弱點，第二章可以買武器之後才會有弱點跟抗性。
>
> 戰鬥時要多一個自動更新訊息的自動對話欄，會根據兩方的實力差別說對話，例如遇到等級差很多的會說這怪好弱，好無聊的爛怪。如果有卡片時會說對方的抗性跟弱點，遇到太強的怪會說，我應該打不贏，要跑嗎？或是感覺會死亡要拼命嗎？
> 這邊根據兩方等級差別對話請產生100句對話內容，根據攻擊之後的效果產生50句對話，例如對方有抗性打了不痛會說，是不是要換武器或招式。根據卡片內容會隨機說出對方的能力或抗性，要怎麼打才會痛。
> 然後另外產生一百句無關緊要的對話，說天氣不錯，還有各式冷笑話。所以要有一個戰鬥即時自動對話更新系統，遊戲一開始會隨機跳到某種狀態依據情況分析給出對應的對話。
>
> 畫面跟UI的部分要在大力優化，目前的顯示太簡陋。要像這張圖片（Image），角色大一點，資訊UI不要擋到角色，但是招式UI可以。戰鬥搞定後再來解決關卡的顯示，然後再綁定事件進去。
> 某些招式要特別事件才能取得。每個武器都有史詩任務跟傳說任務取得新招式。
>
> 數值部分：一開始的怪打個3-5下就掛，到第三層之後怪物的血量會提升並且攻速變快一點點，可以每一回合一定打一下玩家的程度，第五章防禦提升血量變更多攻擊力也提升，玩家不能無腦攻擊一定要防禦，
> 但是防禦攻擊就會中斷，這時候玩家應該可以用到五連擊，玩家要自己判斷要以血換血或是防禦不痛打倒敵人。第七層開始有三種怪物的抗性要出現對應各種武器的抗性/弱點大概有50%，所以有一些怪可能玩家現在不想打，
> 打倒第一章的boss之後NPC對話開放購買武器。怪物抗性之後每層怪都約有20%-80%有（根據怪物設定可能只怕一種武器兩種不怕，或是三種都不並且抗性都50%的事件boss)，玩家要自己切換武器跟裝備來過關。

## 3. 武器系列、種類與等級

**三個系列，各四種。** 每一種都是自己的道具、有自己的等級（用它贏的場數），跟現在的武器一樣。武器種類**沒有特別招式**，
而是有隨等級成長的**能力**。招式來自系列的**熟練度**（§6）。

| 系列 | 種類 | 攻擊前（前置） | 攻擊時 | 防禦 | 等級能力（例） |
|---|---|---|---|---|---|
| **劍** | 長劍（初始） | 無 | 8 方向滑動（等級一），同現在 | 可 | Lv 1–5：每 2 級 +1 個提示；之後每級時間窗 +5% |
| | 雙手劍 | 無 | 從**兩個方向**的滑動起跳（V，等級二）；等待時間短 | **不能防禦** | Lv 1–5：每級等待 −5%；Lv 6+：手勢降一級（V 變成一個方向） |
| | 重劍 | **蓄力 N 秒**（蓄力時有動畫與特效） | 提示少，每下都很重 | 可 | 每級蓄力時間 −5%；Lv 5 滿蓄力可破防 |
| | 短劍 | 無 | 提示快、時間窗短、打很多下 | 可（較短） | 每級 +1 個提示；Lv 5 完美連鎖失誤一次不中斷 |
| **弓** | 獵弓（初始） | 無 | 往後拉再放開，同現在 | 可 | 每級瞄準晃動 −10% |
| | 長弓 | **裝箭袋**（點箭的圖示） | 拉得更用力；靶移動得更久 | 可 | 每級箭袋 +1；每級滿拉傷害 +5% |
| | 十字弓 | **一支一支裝填**（每支點一下，像槍的換彈） | 不用拉：在時機點擊移動的靶 | 可 | 每級裝填時間 −8%；Lv 5 箭能貫穿防禦 |
| | 雙弓 | **設定齊射**：左右滑動決定一次射幾支 | 一次射多支；越多傷害越高、命中範圍越大 | 可 | 每 2 級齊射數 +1 |
| **法杖** | 魔杖（初始） | 無 | 數數、隱藏、依序點，同現在 | 可 | 每 2 級 +1 個圓圈 |
| | 長杖 | **按住集氣**；越久越強 | 穩定節拍的點擊 | 可 | 每級集氣速度 +5% |
| | 法珠 | **畫集氣符號**（五角星或其他圖形，§4） | 符號決定節奏：快、慢、或連點 | 可 | 符號的等級降低；節拍更多 |
| | 法典 | 戰鬥第一次攻擊前**選一頁**（一個符號） | 序列點擊：顯示的順序、更長的連鎖 | 可 | 每級顯示時間 +10% |

- 初始武器（長劍、獵弓、魔杖）不需要前置，玩法同現在。
- 每把武器的說明寫出玩法；戰鬥畫面清楚提示前置與攻擊（一個圖示與一行字：「按住集氣」、「點箭裝填」、「左右滑動設定齊射」）。
- 雙手劍還有一個記憶玩法，是 2026-11-04 的想法（[14](14_WEAPON_PLAY_AND_LOOT.md) 第 2.5 節）。Q59 決定它是否取代上面的 V 形滑動。

## 4. 每種玩法都是一種型態，由資料設定

### 4.1 遊玩型態（程式中的列舉，資料中的名稱）

| 型態（程式） | 資料名稱 | 玩家做什麼 | 用在 |
|---|---|---|---|
| `eSWIPE_WAY` | `swipeWay` | 往 8 個方向之一滑動 | 劍 |
| `eSWIPE_GESTURE` | `swipeGesture` | §4.2 的手勢（V、M、方形） | 雙手劍；招式 |
| `eDRAW_SHAPE` | `drawShape` | 一點一點描出顯示的圖形（§4.3） | 招式；法珠的集氣符號 |
| `eSEQUENCE_CLICK` | `sequenceClick` | 依序點顯示的位置 | 魔杖；法典 |
| `eRHYTHM_TAP` | `rhythmTap` | 跟著節拍點（忽快忽慢的模式） | 長杖；法珠畫完符號後 |
| `eHOLD_CHARGE` | `holdCharge` | 按住；集滿時放開 | 重劍；長杖 |
| `ePULL_RELEASE` | `pullRelease` | 往後拉並對準靶放開 | 弓 |
| `eTAP_TARGET` | `tapTarget` | 在時機點擊移動的靶 | 十字弓 |
| `eRELOAD` | `reload` | 點彈藥圖示裝填 | 長弓、十字弓 |
| `eVOLLEY_SET` | `volleySet` | 左右滑動設定數量 | 雙弓 |
| `eMASH` | `mash` | 盡快連點 | 特殊防禦 |
| `eFREE_SWIPE` | `freeSwipe` | 一段時間內任何地方任何方向的滑動都算 | 劍的絕招 |
| `eFREE_TAP` | `freeTap` | 一段時間內任何地方的點擊都算 | 法杖的絕招 |
| `eFREE_SHOT` | `freeShot` | 一段時間內任何滑動都會射出且必定命中 | 弓的絕招 |

現在的程式已經有大部分的零件：`touch_play.h`（Bow、Slice、Circles、Shape、Mash）、`gesture.h` 與 `cue_track.h`。要做的是給每一種
自己的型態、所有數值從資料讀取，並加入新的（手勢等級、節奏、按住、裝填、齊射、自由模式）。

### 4.2 滑動等級（手勢的難度）

| 等級 | 手勢 | 說明 |
|---|---|---|
| 1 | **8 個方向**之一 | 現在的劍 |
| 2 | **V**（打勾），任意方向 | 一筆兩個方向；雙手劍從這裡起跳 |
| 3 | **M**，任意方向 | 一筆四個方向 |
| 4 | **方形**，從 4 個角任一角開始 | 四個邊 |

武器的等級可以讓提示降一級（§3）。DEX 放寬每一級的容許誤差。

### 4.3 依資料畫圖形

圖形招式讀取：
- **它的點：** 每點的位置與時間；
- **示範片段：** 動畫編輯器的 `.anim` 格式；
- **每點的設定：** 成功與失敗的音效與特效；
- **`allowFail`：** 錯過一點是否結束招式。

遊玩：
1. 示範以 **2 倍速**播放。
2. **第一個點發亮**，並出現一條**線**指出往第二點的路。
3. 每到一個點播放成功音效與特效；錯過播放失敗的。
4. 接著下一點與它的線，直到圖形完成。

### 4.4 DEX

DEX 為每種玩法增加容許度（草案，都在資料中）：
- 滑動角度每點 +1.5°；
- 圖形頂點半徑每點 +1.5%；
- 應對時間每點 +10 ms。

## 5. 絕招（擁有者的新版）

| 武器 | 絕招 | 時間 |
|---|---|---|
| 劍 | **任何地方任何方向的滑動都算**，沒有等待 | 3 秒 |
| 弓 | **任何地方的滑動都會射出且必定命中**，沒有等待 | 2 秒 |
| 法杖 | **任何地方的點擊都算**，沒有等待 | 2 秒 |

- 每次算進去的滑動或點擊都是一擊，各自播攻擊片段（I1）。
- 劍的**普通**攻擊也加入**打勾**：一筆兩個方向的滑動（等級二），作為一種提示。

## 6. 熟練度與招式

- 每個武器系列有**熟練度**，用該系列的任何武器戰鬥都會提升。
- 每個熟練度有 **5 個招式**，該系列的每把武器都能用，在戰鬥畫面中選擇。
- 招式是 `special_moves.json` 的項目（16 §6），各有自己的遊玩型態（§4）。
- 有些招式要靠**特殊事件**取得。
- 每個系列有一個**史詩任務**與一個**傳說任務**，各教一個新招式（筆記寫每個武器：Q65）。

## 7. 弓的彈藥與齊射

**箭袋（裝填）：**
- 弓要先裝箭才能射擊：點**箭的圖示**把箭裝進箭袋。
- 箭袋的容量隨弓的等級增加。
- 箭袋空了，下一次射擊前要重新裝填，就像射擊遊戲的換彈。

**齊射（一次射幾支）：**
- **左右滑動**設定一次射幾支。
- 箭越多，傷害越高、命中範圍越大。
- 一次最多能射幾支隨弓的等級增加。

**在畫面上分清楚兩者**（擁有者：不好解釋）：
- 箭袋顯示成**箭筒裡的箭**，空了時「點擊裝填」會閃爍；
- 齊射顯示成弓上方的**一排扇形箭**，設定後顯示「↔ 3」；
- 第一次各用虛影手指教學一次（同弓的拉弓教學）。

## 8. 法杖的集氣

- 法杖的普通攻擊需要**集氣**。集得越久越強，集氣時間與技能有關。
- 集氣時玩家可以**畫一個集氣符號**（一個圖形，像五角星）。符號決定攻擊的節奏：快、慢、忽快忽慢，或連點好幾下。
- 符號是資料：每個是一個 `drawShape`，加上它給的 `rhythmTap` 模式。

## 9. 戰鬥對話欄

**是什麼：**
- 戰鬥畫面上一行會自己更新的文字，是主角的自言自語。

**什麼時候說話：**
- **開戰時：** 隨機跳到符合戰況的某個狀態（等級差、卡片提示、閒聊）。等級差分五段，從弱很多到強很多。
- **時刻之後：** 被抗性擋下、打到弱點、完美、揮空、自己 HP 低、怪物 HP 低。
- **有怪物卡片時：** 它的抗性、怎麼打才痛、怎麼對付它。
- **閒聊**（天氣、冷笑話），沒有別的要說時。
- 不會很快重複同一句，兩句之間至少隔幾秒。

**台詞**（草稿：[battle_talk/battle_talk_lines.json](../battle_talk/battle_talk_lines.json)，繁中與英文）：

| 類別 | 數量 |
|---|---|
| 等級差 | 100（每段 20） |
| 攻擊之後 | 50 |
| 卡片提示 | 30 個模板，含 `{name}`、`{type}`、`{pct}` |
| 閒聊 | 100，一半是冷笑話 |

## 10. 抗性、弱點與切換武器

**傷害類型：**
- 每隻怪物對每種傷害類型有抗性或弱點：近戰（劍）、遠攻（弓）、魔法（法杖）。
- 例如石頭怪對劍有 50% 抗性。

**玩家看得到什麼：**
- 持有卡片後，怪物的說明會標記它的抗性與弱點，卡片上也會寫。
- 沒有卡片時，玩家從傷害數字與對話欄得知（Q66）。

**戰鬥中切換武器：**
- 戰鬥畫面把擁有的武器顯示成**切換圖示**。
- 切換武器在**武器商人**開放時解鎖：打倒第一章 boss 後 NPC 開放購買武器，第二章遇到武器商人。會跳出**通知**說明戰鬥中可以切換武器。

**哪些怪物有：**
- 一般小怪沒有。
- 第 7 層起：三種怪物，每種類型約 50%。
- 之後的樓層：依資料 20–80% 的怪物有。一隻怪物可能只怕一種，對另外兩種有抗性。
- 事件 boss 可能三種都抗 50%。
- 所以玩家可以先不打某些怪物，並靠切換武器跟裝備來過關（Q67）。

## 11. 難度曲線

| 階段 | 目標 |
|---|---|
| 第 1–2 層 | 怪物 **3–5 下**就倒 |
| 第 3 層起 | HP 更多、攻擊稍快：大約**玩家每攻擊一次，怪物打中一次** |
| 第五章 | DEF、HP、ATK 都提升：玩家**一定要防禦**；防禦會中斷攻擊；這時應該有**五連擊**，自己決定以血換血或防禦 |
| 第 7 層起 | 三種怪物有 50% 抗性（§10） |
| 打倒第一章 boss 後 | 開放購買武器 |
| 之後 | 20–80% 的怪物有抗性或弱點；事件 boss 全部抗 50% |

擁有者的文字混用層與章：Q64 問「第五章」在 Q47 的分段中要怎麼讀。

戰鬥編輯器的成長計算器（13 §4.3）與測試設定是調整這些的工具。

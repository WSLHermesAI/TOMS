# 教學：UI 編輯器

這份教學一步一步帶你用 UI 編輯器修改遊戲的畫面。先在**練習畫面**上操作：一張只為這份教學做的小卡片，所以不會弄壞遊戲的任何東西。
最後再修改一個真正的畫面：戰鬥畫面。

不需要寫程式。這裡的一切都是美術或企劃會做的事：顏色、大小、位置、文字、圖示。要顯示新的遊戲資訊或加入新的按鈕需要程式（第 7 步）。

每個按鈕的說明在 [01_RMLUI.md](01_RMLUI.md)「UI 編輯器」。在編輯器中，**說明 > UI 編輯器教學**（F1）會開啟這一頁。

---

## 0. 本文用語

| 用語 | 意思 |
|---|---|
| **畫面** | 遊戲介面的一頁：標題、戰鬥、商店。每個畫面是 `assets\media\ui` 中的兩個檔案。 |
| **`.rml`** | 畫面上有什麼、依什麼順序：方塊、文字、圖片、按鈕。類似 HTML。 |
| **`.rcss`** | 外觀：顏色、大小、位置、字型。類似 CSS。 |
| **元素** | 畫面上的一個東西：`<div>…</div>` 是方塊，`<span>` 是一行中的一段文字，`<img>` 是圖片。 |
| **id／class** | 你給元素取的名字，讓樣式找得到它。`id="card"` 是一個元素自己的名字；`class="line"` 可以讓很多元素共用。 |
| **規則** | 一條樣式：先是**選擇器**，說明是哪些元素，再在 `{ }` 中寫**屬性**。`#card { left: 312px; }` 會移動 id 為 `card` 的元素。 |
| **設計像素** | 每個畫面都排在 1024 × 768 的頁面上，再縮放到視窗大小。`left: 312px` 指的是那 1024 中的 312。 |
| **綁定** | `.rml` 中的 `{{…}}`：由遊戲填入的值，例如玩家的金幣。 |

會用到的按鍵：

| 按鍵 | 作用 |
|---|---|
| Ctrl+S | 儲存檔案（在這之前磁碟上什麼都不會改變） |
| Ctrl+I | 開關檢查：在遊戲中點擊會選取元素，而不是按下它 |
| F5 | 重新開始預覽 |
| F8 | 疊在遊戲上的 RmlUi 除錯器 |
| F1 | 這份教學 |

## 1. 開啟編輯器與練習畫面

1. 啟動編輯器：`Editor\UiEditor.cmd`（或 `Build\windows-release\bin\ui_editor.exe`）。
2. **說明 > 開啟練習畫面。** 右邊的遊戲會開始新遊戲，地圖上出現一張卡片：*Traveller's Notice*，有一列金幣、一列藥水、一行你的金幣，以及一個
   *Accept* 按鈕。
3. 中間會開啟 `practice.rcss  (教學)`。左邊的清單列出遊戲的每個畫面檔案，最下面是兩個練習檔：`practice.rml` 與 `practice.rcss`。
   它們在 `docs\examples\ui_tutorial`，不在遊戲的資料夾裡：遊戲本身從不顯示它們。

視窗：左邊是**檔案**，中間是**文字**，右邊是**遊戲**，下方是**問題**與**檢視器**。工具列的**預覽**說明遊戲正在顯示什麼
（現在是*練習畫面（教學）*）。

---

## 2. 改一個顏色

1. 在 `practice.rcss` 找到這一行：
   ```css
   #card-title { font-size: 30px; color: #f9e9b1; margin-bottom: 14px; }
   ```
   顏色 `#f9e9b1` 會以它本身的顏色顯示，所以在文字中就看得到。
2. 把 `#f9e9b1` 改成 `#7fd1ff`。
3. 停止輸入。過一下子，遊戲中卡片的標題就變成淺藍色。
4. 清單中這個檔案前面多了 ●：改過、尚未儲存。磁碟上的檔案仍是舊的。

顏色是 `#rrggbb`（紅、綠、藍，各 `00`–`ff`），或在最後加上透明度的 `#rrggbbaa`（`cc` = 80 % 可見）。

---

## 3. 移動與調整卡片大小

1. 找到：
   ```css
   #card { position: absolute; left: 312px; top: 190px; width: 400px; padding: 24px 28px; }
   ```
2. 把 `top: 190px` 改成 `top: 120px`：卡片往上移。
3. 把 `width: 400px` 改成 `width: 460px`：它變寬了。`left` 是它左邊緣的位置。
4. `padding` 是卡片邊緣內的空間：`24px 28px` 表示上下 24、左右 28。

要讓寬度 *w* 的方塊置中，它的 `left` 是 (1024 − *w*) ÷ 2。寬 460 就是 282。

---

## 4. 改文字大小

1. 找到 `.line { height: 42px; line-height: 42px; font-size: 22px; }`。
2. 改成 `font-size: 26px`。兩列的文字變大。每列仍是 42 像素高（`height`），文字位在中間（`line-height` 與 `height` 相同）。
3. 列太擠了？把 `height` 與 `line-height` 都改成 `48px`。

---

## 5. 加一列有圖示的資料

1. 開啟 `practice.rml`（在清單中點它）。
2. 找到藥水那一列：
   ```html
   <div class="line"><img sprite="potion_red"/><span class="label">Red potion</span><span class="value">x 2</span></div>
   ```
3. 複製這一行，貼在下面，改成黃鑰匙：
   ```html
   <div class="line"><img sprite="key_yellow"/><span class="label">Yellow key</span><span class="value">x 1</span></div>
   ```
4. 出現第三列，有鑰匙的圖。它的外觀和其他列一樣，因為它有相同的 class。

`sprite="…"` 是依名稱取自遊戲圖集的圖。名稱就是 `art_raw\sprites` 中 PNG 的名稱（不含 `.png`），或 `assets\media\atlas\game.atlas`
中的各行。不存在的名稱什麼都不會顯示。

---

## 6. 只改一個元素的樣式

這些列共用 `class="value"`，所以改 `.value` 會改到全部。要讓其中一個不同，給它第二個 class：

1. 在 `practice.rml` 的鑰匙那一列，把 `class="value"` 改成 `class="value rare"`。
2. 在 `practice.rcss` 的最後加上新的一行：
   ```css
   .rare { color: #ff8a65; }
   ```
3. 只有鑰匙的 `x 1` 變成橘色。

會遇到的選擇器：

| 選擇器 | 選到 |
|---|---|
| `#card` | `id="card"` 的元素 |
| `.line` | `class` 中有 `line` 的每個元素 |
| `.line img` | 每個 `.line` 裡面的 `<img>` |
| `.btn:hover` | 滑鼠在上面時的 `.btn` |
| `div` | 每個 `<div>` |

兩條規則設定同一個屬性時，越精確的那條勝出（`#id` 勝過 `.class` 勝過標籤）。一樣精確時，後面的那條勝出。

---

## 7. 顯示遊戲中的資訊

1. 在 `practice.rml` 找到 `<div id="you">{{hud.res_line}}</div>`。`{{hud.res_line}}` 由遊戲填入：地圖上方那一行的金幣、水晶與鑰匙。
2. 改成 `<div id="you">{{hud.hp_text}}</div>`：這一行改為顯示生命值。
3. 畫面能顯示的值列在 `src\core\game\ui\ui_state.h`（地圖是 `hud.…`，戰鬥是 `battle.…`，依此類推），每個畫面使用它自己那部分的值。

**需要程式的事：**

- 那份清單裡沒有的值；
- 會做事的新按鈕（`data-event-click`）；
- 依遊戲條件顯示或隱藏（`data-if`）；
- 由遊戲資料產生的清單（`data-for`）。

它們存在之後，你仍然可以擺放並設定樣式。修改外觀時，請保持 `data-…` 屬性原樣。

---

## 8. 找出是什麼在設定元素的樣式（檢查）

1. 按 **Ctrl+I**（或工具列的*檢查*）。現在在遊戲中點擊是選取，不是按下。
2. 點擊遊戲中的 **Accept** 按鈕。
3. `practice.rml` 會開在按鈕那一行。下方的**檢視器**顯示 `div#accept.btn.btn-yes`，並列出指定它的規則：
   - `common.rcss` 的 `.btn { … }`（每個按鈕的形狀）；
   - `.btn-yes { … }`（綠色）；
   - `practice.rcss` 的 `#accept { … }`（這個按鈕的大小）。
4. 在檢視器中雙擊 `#accept`：`practice.rcss` 會開在那條規則。改成 `height: 56px; line-height: 56px;`。
5. 再按一次 **Ctrl+I**，把點擊還給遊戲。

`common.rcss` 是遊戲每個畫面共用的：只有在你想改全部畫面時才改它。

想看全貌（每個元素、它最後的每個值、它占的方塊），**F8** 會在遊戲上開啟 RmlUi 本身的除錯器；再按一次 F8 關閉。

---

## 9. 出錯時（問題）

1. 在 `practice.rcss` 把一個屬性拼錯：把 `.rare` 中的 `color` 改成 `colr`。
2. 鑰匙的數字變回黃色（這條規則被忽略），下方的**問題**會列出 RmlUi 關於它的訊息。有寫出檔案與行號的訊息，雙擊即可開啟那裡。
3. 改回正確拼法：下一次修改後訊息就會消失。

畫面什麼都不顯示，通常是 `.rml` 中少了 `>` 或 `"`；問題清單會說明 RmlUi 停在哪裡。

---

## 10. 把練習畫面還原

練習檔是儲存庫的一部分；請為下一個人保持原樣。

1. 開著 `practice.rcss`：**檔案 > 還原檔案**。`practice.rml` 也一樣。
2. ● 標記消失，卡片回到原來的樣子。

如果不小心存檔了，問程式，或在 Git 中執行：`git checkout -- docs/examples/ui_tutorial`。

---

## 11. 換成真正的畫面：戰鬥

1. **預覽**：選擇 `battle — battle_bow`。遊戲會開啟一場用弓的戰鬥。
2. 開啟 `battle.rcss`。戰鬥的標題是：
   ```css
   #title  { position: absolute; left: 262px; top: 14px; font-size: 38px; color: #ffcaa8; }
   ```
   試試 `font-size: 44px`，看遊戲中的標題。
3. **語言**：選擇日本語或 Español。遊戲的文字換成那個語言（只在這裡：遊戲本身的設定不變）。檢查長的行是否仍放得下；跑進下一行的文字需要
   更多空間（更高的方塊，或更小的字）。
4. 滿意了？**Ctrl+S**。現在磁碟上的檔案會改變，任何執行中的遊戲（TomsEditor、除錯版）也會顯示它。
5. 不滿意？**還原檔案**。
6. 提交你改過的 `.rcss`／`.rml`（見團隊計畫 [../../project/zh_TW/11_TEAM_PLAN.md](../../project/zh_TW/11_TEAM_PLAN.md) 第 4 節）。

**真正畫面的規則：**

- 不要重新命名或刪除遊戲用到的 `id`、`class` 或 `data-…` 屬性：遊戲靠它們找到自己的部分。請改在 `.rcss` 中改外觀。不確定時問程式。
- 玩家會讀到的新文字要放進 `assets\data\text.json`（所有語言），而不是寫在 `.rml` 裡；畫面再透過綁定顯示它。那是企劃與程式的部分。
- 畫面中出現新字元後（新的符號、新的中文），執行 `python tools\make_ui_font.py`。
- 存檔前，用字比較長的語言（西班牙文、日文）檢查畫面。

## 12. 看起來不對時

| 問題 | 原因與做法 |
|---|---|
| 輸入時遊戲沒有變化 | 修改會在短暫停頓後預覽。還是沒有？看問題清單；這條規則可能被忽略了（拼錯的屬性、少了 `;`） |
| 練習卡片不見了 | 在預覽中選擇*練習畫面（教學）*（或 說明 > 開啟練習畫面）；按 F5 重新開始 |
| 圖片什麼都沒顯示或是白色方塊 | 圖集中沒有那個 sprite 名稱，或 `.rml` 沒有連結 `_atlas.rcss` |
| 在遊戲中點擊沒有反應 | 檢查開著（按 Ctrl+I 關閉） |
| 遊戲的視窗是黑的 | 顯示無法啟動（和 TomsEditor 一樣需要支援 Direct3D 11 的顯示卡）；狀態列會說明原因 |
| 編輯器中有我的修改，但另外執行的遊戲沒有 | 還沒存檔（●）。Ctrl+S |
| 編輯時磁碟上的檔案被改了 | 狀態列會說明。你的文字會保留；還原檔案會改用磁碟上的 |

# 15 — 戰鬥改版：讓玩家愛上的一個循環（設計）

**狀態：** 設計，2026-10-31（擁有者：「改版戰鬥畫面：從遊戲玩法文件中整合一些想法，讓玩家愛上戰鬥」）。遊戲中尚未實作；問題在 §9。

**試玩：** [../battle_editor/revamp_prototype.html](../battle_editor/revamp_prototype.html) 是一個可以玩的快速原型（用瀏覽器開啟，離線可用）：
整個循環、三種武器玩法、破防、連鎖、絕招特寫、手感與結算畫面，並有 Q34–Q37 的切換。數字都是隨意訂的；用來感受這些想法，不是用來調整數值。

這些想法不是新的。它們分散在四份文件中，有些已實作，有些只寫下來：[07](07_GAMEPLAY_PLAN.md)（支柱、武器、招式名稱）、
[11](11_BATTLE_DATA.md)（戰鬥者、狀態、劇情戰鬥）、[13](13_BATTLE_EDITOR.md) §6（即時策略戰鬥的十個想法）與
[14](14_WEAPON_PLAY_AND_LOOT.md)（每把武器自己的玩法、刷寶）。引擎也有新工具：節點特效（光暈、動態模糊、殘影；
[../../engine/zh_TW/18_NODE_EFFECTS.md](../../engine/zh_TW/18_NODE_EFFECTS.md)）。本文件把它們整合成**一場戰鬥**，並排出工作順序，每一步都是玩家感受得到的改變。

## 1. 玩家為什麼會愛上一場戰鬥，以及我們現在在哪裡

一場讓玩家想再玩的戰鬥，每隔幾秒就會給玩家：

| 玩家得到的 | 我們現在 |
|---|---|
| **可以判讀的東西：** 怪物的下一招，所以有選擇 | 已實作：意圖，以文字顯示在怪物上方（13 §9.2） |
| **選擇：** 現在攻擊、防禦、等待、使用技能 | 部分：攻擊與防禦；技能只有一個「主動」按鈕 |
| **屬於那把武器的手上玩法** | 還沒有：弓、劍、杖共用同一條點擊量條（14 §2） |
| **大場面：** 破防、爆發、有名字的終結技 | 部分：有破防與「完美！」；沒有終結技、沒有招式名稱、沒有特寫畫面 |
| **手感：** 每一擊都有重量 | 很少：數字升起，怪物退縮 |
| **顯示成長的獎勵：** 武器升級、新招式快到了、掉卡片 | 部分：武器的勝場在背景計算；一則卡片通知 |

最大的兩個缺口：**戰鬥沒有手感**（沒有打擊停頓、沒有震動、每擊同一個音效），以及**沒有回報**（戰鬥結束時沒有一個時刻顯示玩家得到什麼、接下來是什麼）。
兩者都比武器玩法便宜，所以先做（§8）。

畫面也很擁擠：敵人計時、攻擊量條、防禦條、必殺量表、主動按鈕，以及最多三個意圖，全都同時搶視線（§6）。

## 2. 一場戰鬥的循環

從史萊姆到 Vorkath，每場戰鬥都是同樣的節奏，玩家學一次就會：

```
   判讀 ────────► 應對 ────────► 玩法 ────────► 破防 ────────► 爆發 ────────► 獎勵
 怪物上方的      在它打到之前    武器自己的      量表滿了：      絕招、有名字    評價、武器經驗、
 意圖           防禦／招架／    玩法            怪物暈眩        的招式、特寫    卡片、寶箱鑰匙、
 （13 §6.1）     閃避，或攻擊    （14 §2）       （13 §6.4）     （§3.4）        「下一級：新招式」
                （13 §6.2）                                                    （§3.6）
```

普通戰鬥 **20–40 秒**（兩到四次交手）；頭目 **60–120 秒**，分階段（§3.5）。行動裝置的時間（07 支柱 4）：一場戰鬥放得進短暫的休息。

## 3. 各個部分，整合起來

每個部分都寫出來源與已實作的程度。

### 3.1 判讀：怪物告訴你它要做什麼

- **意圖圖示**取代文字（13 §6.1，第 4 步還要做）：拳頭（攻擊）、舉起的錘子（重擊）、三道痕（連打）、發光的符文（法術）、盾牌（防禦），
  圓環填滿到攻擊落下的時刻。前幾場戰鬥圖示下方保留一小行文字，之後隱藏（一個設定）。
- **重擊或法術落下前最後 0.5 秒：** 怪物發光（節點特效 `glow`，18），並播放一個短音效。招架的時機看得到、聽得到，不用從量條猜。
- **每隻怪物一個時鐘，沒有全域時鐘條：**「敵人攻擊計時」這一列移除（它只顯示最近的一個）。

### 3.2 應對：一個防禦按鈕，三種結果

- 已實作（13 §9.2）：防禦減輕傷害；完美防禦**招架**重擊（踉蹌、×2 傷害）；連打打斷連擊；好的連擊打斷法術；滿集氣打破防禦。
- **更容易判讀：** 防禦條改成**一個大的防禦按鈕**，它的圓環顯示時機；結果以文字跳在玩家身上：*擋下*、*招架！*、*太早*。
  （五段式防禦條保留為 `battle.json` 中的選項。）
- **武器有各自的角色**（13 §6.5）：弓可以在怪物蓄力時射擊而不被打到（距離）；劍的完美算作招架；杖的滿集氣打破防禦與法術。
  依怪物選武器變成一個決定，而試用武器（07 §15）已經教過它們。

### 3.3 玩法：每把武器自己的玩法

來自 14 §2（擁有者的筆記，2026-10-30），依 14 §4 提議的順序：

| 武器 | 玩法 | 等級增加 | 絕招 |
|---|---|---|---|
| 弓 | 往後拉再放開射向目標（14 Q28） | 每次射更多箭 | 目標出現在不同地方；全中＝會心連射 |
| 劍 | 劃過敵人，每劃一次一刀 | 每次攻擊更多刀 | 依顯示的方向劃；接著記憶連招 |
| 杖 | 依節奏點圈圈（應援團） | 更多圈圈、更快 | 畫魔法陣 |

三者都回報**同一個結果等級**：失誤／命中／很好／完美，所以 `weapon_play.json` 的 `results`、它們的粒子與 `attack_big` 動畫（13 §10）都繼續可用，
而**招式名稱**（07 §5.4）為結果命名：打得好是*虎虎生風四連擊*，打不好是*虎頭蛇尾*。失誤依武器等級的規則讓連擊退回（07 §5.6），和現在一樣。

### 3.4 破防與爆發：大場面

- **破防**（已實作，13 §6.4）：命中的點累積量表；滿了怪物暈眩 3 秒並受到 ×1.5。
- **新：破防時刻是一個場面。** 畫面稍微變暗，怪物閃白（節點特效 `flash`），「BREAK!」橫過畫面，音樂打一個重拍。玩家知道：*就是現在*。
- **絕招**（必殺量表，14 的絕招）變成每把武器的**終結技**：一個特寫畫面（英雄的臉或武器滑過，0.6 秒），接著武器的絕招玩法（§3.3），
  然後是帶殘影與光暈的 `attack_big` 動畫（18）。在破防時間內使用 ×2。
- **完美連鎖**（13 §6.9）：連續完美讓玩家旁的計數器上升（*連鎖 ×3*）；每一級增加傷害並讓必殺量表更快累積。失誤歸零。這是高手追求的東西。

### 3.5 有故事的怪物：階段

- 已實作：怪物事件（13 §9.1）：HP 低於 N% 時，一句台詞、數值改變、變身、召喚。
- **用在每個頭目與部分菁英怪：** 石巨人在 50% 時符文燃起（更快、新招式），在 20% 時變成核心；Vorkath 怒吼並召喚第二型態。
  階段轉換也是一個場面：短暫停頓（0.8 秒）、一句台詞、怪物的 `special` 動畫。
- **弱點與屬性**（13 §6.7）：怪物的卡片顯示它的弱點（火、冰、穿刺）；命中弱點傷害更高並顯示*弱點！*。收集卡片就學會弱點，所以卡片收集（07 §3）回饋到戰鬥。

### 3.6 獎勵：戰鬥結束是一個回報

一個 2–3 秒的結算畫面，點一下可以跳過：

```
        ★ ★ ★   S                      （評價：時間、受到的傷害、完美次數）
   獵人之弓  Lv 3  ████████░░  8 / 10      ← 武器升到下一級還需要的勝場
   下一級：4 個點，二連射                    ← 下一級增加什麼（07 支柱 2）
   + 12 金幣   + 7 經驗   🂠 史萊姆卡片（2）  + 1 寶箱鑰匙（14 §3）
```

- **每場戰鬥都顯示武器的進度**（07 支柱 2：「玩家應該想升到下一級去看新招式」）。現在它在背景默默計算。
- **評價**（S／A／B／C）獎勵打得好，而不只是贏：S 多給一點（金幣、卡片機率）。這是「再試一次」的動力。
- **掉落物**之後供應刷寶（14 §3）：部分怪物掉寶箱鑰匙，特殊怪物掉特殊寶箱。

### 3.7 戰鬥前：一個小選擇

- **有冷卻的技能，在戰鬥前選擇**（13 §6.6）：從技能樹的主動技能中選兩格（*擋下一擊的護盾*、*時間變慢 3 秒*、*一次免費完美*），
  每個都有冷卻圓環。即時進行，但什麼時候用就是選擇。
- 卡片的弱點（§3.5）在遭遇時顯示，玩家可以在開戰前換武器。

### 3.8 手感：每一擊都打得到位

來自 13 §6.10，都很便宜，也都能在 `battle.json` 調整：

| 效果 | 何時 | 份量（初步猜測） |
|---|---|---|
| **打擊停頓**（雙方凍結） | 很好／完美命中、招架、破防 | 40／70／90 毫秒 |
| **畫面震動** | 受到重擊、完美、破防、終結技 | 3–10 像素，150–300 毫秒 |
| **依等級的傷害數字** | 每一擊 | 依結果改變大小與顏色；*弱點！*、*招架！*、*連鎖 ×3* 等字 |
| **依等級的音效** | 每一擊 | 命中／很好／完美／招架／破防各自不同 |
| **怪物退縮** | 每次命中 | 已實作（受擊動畫） |
| **殘影與光暈** | 終結技、完美 | 武器動畫上的節點特效（18） |
| **慢動作** | 戰鬥的最後一擊 | 0.4 秒、30% 速度，接著結算畫面 |

**「減少震動與閃光」**設定可以調低震動、閃光與慢動作（舒適與無障礙）。

## 4. 畫面

直向（單手拿手機）與橫向使用同樣的元件；位置由 12 決定。

```
 直向                                        橫向
 ┌─────────────────────────┐                ┌──────────────────────────────────────────────┐
 │ [⚔ 2.1s]  [🛡 3.0s]      │ 意圖           │ [⚔ 2.1s] [🛡]              連鎖 ×3     ☰     │
 │   怪物       怪物        │                │ 英雄        ─────────►     怪物      怪物     │
 │ ▓▓▓▓▓▓░░  ▓▓▓▓░░        │ HP + 破防      │ ▓▓▓▓▓▓▓▓    武器玩法        ▓▓▓▓░░  ▓▓▓░░    │
 │                         │                │             在怪物上方                        │
 │   （武器玩法在上方，     │                │                                              │
 │     怪物上面進行）       │                │ [技能][技能]            [防禦]    [攻擊]      │
 │   英雄   ▓▓▓▓▓▓▓▓ HP    │                │ ◉◉◉○○ 必殺                                  │
 │ 連鎖 ×3                 │                └──────────────────────────────────────────────┘
 │ [技能] [技能]  ◉◉◉○○    │
 │ [  防禦  ] [  攻擊  ]   │ 拇指
 └─────────────────────────┘
```

- **兩個給拇指的大區塊**：**防禦**是按鈕；**攻擊不是**（擁有者，2026-10-31：先按攻擊再做動作多了一步）。攻擊準備好時，武器玩法直接在怪物上方等待，
  第一次觸碰就開始；攻擊區塊只顯示*準備好*或*恢復中*（圓環填滿）。技能與必殺量表在旁邊；絕招是按鈕，會取代正在等待的玩法。
- **武器玩法在怪物上方進行**，就在視線本來所在的地方，而不是底部的一條。
- **移除：** 全域敵人計時列、五段式防禦條（成為選項）、長的紀錄文字（改成在發生的位置跳出短字；紀錄保留在戰鬥編輯器）。

## 6. 維持不變的

- 戰鬥仍是**即時**，戰鬥中**沒有選單**。
- 13 §9 實作的規則保留；這次改變的是它們如何呈現與感受，並在上面加上武器玩法。
- 沒有 `"moves"` 的怪物仍和現在一樣戰鬥，所以在內容跟上之前，舊樓層照常運作。

## 7. 衡量「玩家愛上它」

在還沒有玩家可以問之前，由戰鬥編輯器的紀錄回答（13 §4.5）：

- **戰鬥長度：** 普通 20–40 秒，頭目 60–120 秒。
- **每場的決定：** 至少三個時刻，防禦、攻擊與技能都可行，而其中一個是對的。
- **熟練玩家的完美率：** 40–60%（更高：太簡單；更低：令人挫折）。
- **「再試一次」：** 面對新怪物三次內拿到 S 評價。

之後：每一步做一次簡短的試玩（五個人，觀察，問「你喜歡什麼、什麼讓你困惑」）。

## 8. 工作順序

每一步都是玩家感受得到的，也都可以單獨推出：

| 步驟 | 內容 | 規模 | 需要 |
|---|---|---|---|
| R1 | **手感：** 打擊停頓、震動、依等級的數字與文字、依等級的音效、最後一擊慢動作；減少特效設定 | 小 | Q34 |
| R2 | **獎勵：** 有評價、武器進度與下一級預告、掉落物的結算畫面 | 小 | Q35 |
| R3 | **畫面：** 兩個拇指按鈕、意圖圖示、沒有全域時鐘、玩法在怪物上方（直向與橫向） | 中 | Q36 |
| R4 | **破防與爆發：** 破防場面、完美連鎖、帶節點特效的終結技特寫 | 中 | — |
| R5 | **弓自己的玩法**（14 §2.1）與招式名稱，接著劍（§2.2）與杖（§2.3） | 大 | 14 Q27–Q30 |
| R6 | **選擇：** 技能配置、卡片上的弱點 | 中 | Q37 |
| R7 | **劇情戰鬥：** 每個頭目與部分菁英怪的階段；刷寶的寶箱鑰匙（14 §3） | 中 | 14 Q31–Q33 |

先做 R1 與 R2：幾天內戰鬥就有手感、有回報，其他都不用改。

## 注意

- **交談** 與以前相同：玩家走到 NPC 的格子上，或站在上面按 Enter。
- **站在好幾層樓的 NPC** 在每一層都共用它的話題，除非話題設定了 *在哪一層交談*。
- **閒聊台詞與完成後對話會重複播放**，所以其中有獎勵（`addStat`、`setStat`、`give`）時測試會失敗。
- **Android 的後備字型** 已寫好且可以建置，但還沒在裝置上看過實際執行。
- **Git LFS：** GitHub 免費額度為 1 GB 儲存空間與每月 1 GB 下載量；每次 clone 會下載約 100 MB 的 `Editor/bin`。
- **沒有開啟專案資料夾的事件編輯器** 是沙盒：儲存只會把編輯標示為已儲存，不會寫入任何檔案。

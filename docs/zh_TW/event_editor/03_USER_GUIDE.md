# 03 — 使用指南

> 英文原文：[03_USER_GUIDE.md](../../event_editor/03_USER_GUIDE.md)

第 1 節是今天手動的做法。第 2 節是同樣的工作在編輯器中怎麼做；
HTML 事件編輯器（[tools/web_editors/](../../../tools/web_editors/index.html)）可以看到每個畫面，它的教學能讓你
一步一步完成 2.2 到 2.5 節。

## 1. 今天：手動編輯 JSON

### 新增事件

1. 在 `assets/data/events/` 中選一個事件池：任何樓層都能用的 `pool_common.json`，或某一章專用的
   `pool_actNN.json`。
2. 在它的 `"events"` 陣列中加一筆紀錄：
   ```json
   { "eventId": "ev_village_scarecrow", "kind": "whisper", "text": "ev_village_scarecrow.text" }
   ```
3. 在 `assets/data/text.json` 的 `"strings"` 底下加上文字，每種語言一項：
   ```json
   "ev_village_scarecrow.text": { "zh_TW": "稻草人轉過頭來看你。", "en": "The scarecrow turns its head to watch you.", ... }
   ```
4. 在每個能抽到它的樓層的 `"events"` 陣列中列出這個 ID，例如
   `assets/data/story/floors/F02.json`。

### 檢查

目前還沒有可以執行的檢查工具。請手動檢查以下幾點，或寫個小腳本：

- 這個 `eventId` 不在其他事件池中。
- `text` 鍵存在於 `text.json`。
- 至少有一個樓層列出這個 ID；否則它永遠不會出現。
- 樓層列出的每個 ID 都存在於某個事件池。

## 2. 在編輯器中（規劃中）

開啟 `toms_editor`，選 **事件** 分頁。它會從專案根目錄載入所有事件池、樓層設定和
`text.json`。

### 查出事件出現在哪裡

1. 在事件樹中輸入 ID 的一部分，或在 **章節** 中選它的事件池。
2. 點這個事件。圖上會標出它的事件池、每個能抽到它的樓層，以及它的文字鍵。
   屬性面板會把這些樓層列成標籤。

*在 HTML 編輯器中：**關係圖** 分頁。點 `ev_common_cache_wall`。*

### 新增事件

1. 在事件樹中對事件池按右鍵，選 **新增事件**。
2. 在屬性面板中輸入 ID；文字鍵會自動填成 `<id>.text`。
3. 選擇 **類型**。
4. 在 **樓層** 底下點 **新增樓層…**，勾選樓層。
5. 輸入每種語言的文字。還沒寫的語言保持勾選 **todo**。
6. 按 **Ctrl+S**。事件池檔、樓層檔和 `text.json` 會一起儲存。

*在 HTML 編輯器中：教學第一部分。*

### 重新命名事件

在屬性面板中修改 `eventId`。每個列出它的樓層和它的文字鍵都會跟著改，算一個復原步驟。

### 修正問題

1. 勾選 **只看有問題的**，或打開 **問題** 面板。
2. 雙擊一列來選取它。
3. 使用該列的快速修正，或在屬性面板中手動編輯。

*在 HTML 編輯器中：**問題** 分頁，顯示今天資料中真實存在的問題。*

### 補齊第 4–10 章

樓層 F22–F70 已經列了 92 個沒有事件池的事件 ID。在問題面板中，選取某一章的
*缺少的事件 ID* 各列，選 **在事件池中建立事件…**，再選（或建立）`pool_act04`。
編輯器會為每個 ID 建立一筆紀錄，並連到它的佔位文字。
接著設定每個事件的類型並撰寫文字。

## 3. 快速鍵（規劃中）

| 按鍵 | 動作 |
|---|---|
| Ctrl+S | 儲存變更的檔案 |
| Ctrl+Z / Ctrl+Y | 復原 / 重做 |
| Ctrl+F | 跳到事件樹的搜尋框 |
| F5 | 從磁碟重新載入 |
| Del | 刪除選取的事件（若有樓層使用它，會先詢問） |
| 拖曳 / 滾輪 | 平移 / 縮放圖 |

# 02 — 編輯器設計

> 英文原文：[02_EDITOR_DESIGN.md](../../event_editor/02_EDITOR_DESIGN.md)

事件編輯器是 `toms_editor`（Qt6 Widgets）中的一個分頁，做法和動畫、粒子編輯器一樣：
中央視圖周圍放停駐面板、同一套深色主題、一個歷程面板，以及自動備份。
[tools/web_editors/](../../../tools/web_editors/index.html) 中的 HTML 事件編輯器可以看到每個部分實際運作。

## 2. 面板

### 篩選列（`EventFlowView` 中已有）

| 控制項 | 作用 |
|---|---|
| 章節（事件池） | 只顯示一個事件池，以及和它相連的樓層與文字 |
| 類型 | 只顯示一種事件類型 |
| 樓層 | 樓層範圍，1–70 |
| 只看有問題的 | 隱藏所有沒有問題的東西 |
| 摘要 | 節點數和問題數 |

### 流程圖（已有，唯讀）

由左到右的欄：**樓層 · 事件池 · 事件 · 文字鍵**。樓層從左邊連到事件，
事件池也從左邊連到事件，所以每條指向事件的線都朝右。顏色：事件池藍色、事件依類型、
樓層灰色、文字鍵綠色；有問題的東西會加上橘色外框。

- 拖曳平移，滾輪縮放。
- 點一個節點：標出它和所有碰到它的線，並在屬性面板中選取它。
- 雙擊樓層：在關卡編輯器分頁中開啟該樓層設定。

### 事件樹（新）

事件池是資料夾，事件在裡面。這是用名稱找東西最快的方法。右鍵選單提供
*新增事件*、*複製*、*刪除*、*移到事件池…*。

### 屬性面板（新）

對**事件**：

| 欄位 | 編輯方式 |
|---|---|
| `eventId` | 文字框。改名會更新每個列出它的樓層，並改掉 `.text` 鍵，算一個復原步驟 |
| `kind` | 已知類型的下拉選單 |
| 事件池 | 下拉選單；改變它會把這筆紀錄移到那個事件池檔 |
| 樓層 | 每個列出此事件的樓層一個標籤，再加上 *新增樓層…*。這會編輯樓層檔 |
| 文字 | 每種語言一個多行文字框，附 *todo* 勾選框，以及遊戲字型的預覽 |

對**樓層**：它的 `act`，以及依序排列的事件清單，附 *新增* 和 *移除*。對**文字鍵**：
只有各語言的文字框。

### 問題（新）

每個問題一列：規則圖示、ID，以及在哪裡找到。雙擊會選取該節點。有些規則有快速修正：

| 規則 | 快速修正 |
|---|---|
| 缺少的事件 ID | *在事件池中建立事件…*（預先填好 ID，文字取自佔位鍵） |
| 孤立事件 | *加到樓層…* 或 *刪除* |
| 缺少文字鍵 | *建立文字* |

## 3. 儲存

- 編輯器把整張圖放在記憶體中。**儲存**（Ctrl+S）只寫入有變更的檔案：
  動到的事件池檔、樓層設定和 `text.json`。
- 寫出的 JSON 用 2 格縮排並保留鍵的順序，讓差異保持很小。`_comment` 區塊會保留。
- 覆寫之前，會像其他編輯器一樣把每個檔案複製到備份資料夾。
- 如果檔案在載入後於磁碟上被改過，儲存前會先詢問。
- `reload()` 會從磁碟重新讀取；若有未儲存的變更會先詢問。

## 4. 復原

每次編輯是一個 `QUndoCommand`，並顯示在歷程面板中。會動到好幾個檔案的編輯
（改 ID、把事件移到另一個事件池）是一個指令，所以按一次 Ctrl+Z 就會全部還原。

## 5. 開發階段

| 階段 | 工作 | 份量 |
|---|---|---|
| 1 | 把 `event_graph.*` 和 `event_flow_view.*` 加進 `src/editor/CMakeLists.txt`（和其他檔案一樣加 `QT_NO_EMIT`）。在 `editor_window.cpp` 中建立分頁。針對一份小型測試資料為 `loadEventGraph` 加一個無介面測試。 | 小 |
| 2 | 點選與標示。屬性面板。能儲存事件池、樓層和 `text.json` 的寫入器。復原。 | 中 |
| 3 | 事件樹和附快速修正的問題面板。01 第 3 節中的額外規則。縮放，以及讓 70 層樓保持可讀的配置。 | 中 |
| 4 | 批次工作：用樓層已經使用的 ID 建立 `pool_act04` … `pool_act10`；給譯者用的文字 CSV 匯出與匯入。 | 小 |

## 6. 待決問題

- 樓層的事件清單應該保持明確列出，還是樓層只寫它的事件池、讓產生器決定抽什麼？
  目前是明確列出，編輯器也照資料走。
- `_v2` … `_v5` 的 ID 是不是同一個事件的變體（同類型、不同文字）？如果是，
  屬性面板可以把它們歸在同一個事件底下。
- 發行前哪些語言是必要的？這決定 *未翻譯* 是警告還是錯誤。

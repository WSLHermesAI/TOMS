本規劃整理自負責人在 2024 年寫的設計筆記 [魔塔.txt](../魔塔.txt)（有日期的段落：2 月 2 日、5 月 10 日、6 月 2 日）。

- 三種新武器（筆記：「再幫我想三種新的武器還有打敵人的遊玩方式」）；
- 筆記留下的待決問題。

本文件自己提出的內容標示為 **（提案）**，其餘都來自筆記。負責人 2026-10-20 的回答在第 11 節，並已寫進它們改變的
各節，標示為 **負責人（2026-10-20）**。

這裡的內容都還沒有實作。第 1 節說明目前的戰鬥，方便對照每個點子。

## 1. 遊戲目前有什麼

- **戰鬥 v2**（`src/core/game/core/game_combat.cpp`、`assets/data/battle.json`）：
  - **攻擊條**與**防禦條**自己移動，點一下就停住其中一條；
  - 指標的位置決定威力（綠／藍／紅區，武器的 `maxMult`）；
  - 敵人依自己的計時攻擊；
  - 命中會累積**必殺技**。
- **武器**（`items.json`）各自帶有 `bar` 設定：起始速度、最高速度、加速時間、各區寬度、`maxMult`。目前有 4 把，
  包括魔杖與雙刃匕首。
- **屬性**（`stats.json`），每點目前的效果：

  | 屬性 | 效果 |
  |---|---|
  | STR | ATK |
  | DEX | 攻擊條命中區（`hitZone`） |
  | AGI | 縮短攻擊條的冷卻 |
  | VIT | 最大 HP |
  | INT | 功法威力 |
  | LUK | 金幣獲得量 |

- **遊戲中已有：**10 章 70 層（[29_FLOOR_REDESIGN.md](29_FLOOR_REDESIGN.md)）、金幣、經驗與等級、商店、鍛造、
  功法、裝備主動技、轉生、大廳與關卡選擇。

筆記中的戰鬥點子是**從戰鬥 v2 延伸**出來的：它的能量條會變成每種武器自己的玩法。

## 2. 核心方向

1. **武器 = 玩法。**每種武器有自己的觸控小遊戲，不只是數值不同。
2. **看得見熟練度。**玩家越常用一把武器：
   - 連招越長；
   - 攻擊越強；
   - 動畫與特效越誇張（「連招越多動畫越誇張攻擊力也越強」）。
   - 要讓玩家想升到下一級去用新招式。
3. **卡。**目前是**收集系統**：打倒怪物時有機會得到牠的卡（第 3 節）。在一場遊戲中買卡、合卡，並用寶石提高能合到
   幾星，是之後的點子。
4. **手機玩家的時間。**初階武器升級要快；武器進階後升級要慢慢來。

## 3. 卡

**負責人（2026-10-20）：目前卡只是收集系統。**

| 規則 | 內容 |
|---|---|
| 卡記錄什麼 | 每隻怪物：玩家打倒牠幾次，以及牠打倒玩家幾次 |
| 取得卡 | 每次打倒怪物時有機率：**第一張** 100%，**第二張**（同一張卡）50% |
| 機率在哪裡設定 | **在怪物資料中**（`enemies.json`），每隻怪物可以不同 |

怪物資料中的機率 **（提案：欄位名稱）**：

```json
"slime": { "hp": 24, "atk": 8, ..., "card": { "chance": 1.0, "repeatChance": 0.5 } }
```

- `chance`：玩家還沒有這張卡時得到它的機率。沒寫就是 1.0。
- `repeatChance`：再得到一張的機率。沒寫就是 0.5。
- 這些數字（張數、打倒次數、被打倒次數）存在長期存檔（meta save），跨越每場遊戲與轉生 **（提案）**。玩家選單中的
  卡片頁顯示它們 **（提案）**。

### 3.1 之後：合卡（來自筆記，目前不做）

來自筆記：

| 步驟 | 規則 |
|---|---|
| 遊戲中 | 打死怪物得到**金幣**，只能在這場使用 |
| 過關 | 得到**寶石**（會保留） |
| 每關開始 | 玩家身上的寶石可以換金幣，**每場可換的金幣有上限** |
| 金幣 | 買**卡** |
| 卡 | **合卡**，提升這場遊戲中角色的星數 |
| 大地圖 | 用寶石升級角色，提高角色**最多能合幾星** |
| 派出欄位 | 每場戰鬥能派的角色數量固定。玩到後面，星數上限低的角色會佔住欄位卻無法再升級，所以必須在大地圖提高星數上限 |

筆記以皇室戰爭為參考（「學皇室戰爭中的回合制機制」）。

合成後的卡在戰鬥中怎麼作用（與主角並肩的夥伴，或主角的技能與招式），等做這部分時再決定。先做上面的收集，
收集到的張數就是之後合卡要用的。

## 4. 戰鬥：兩個能量條

來自筆記（最新的戰鬥段落）：

- **垂直條：集氣。**
  - 第一次點擊是集氣，集越多攻擊力越強。
  - 力量越大，水平條的指標移動**越快**。
- **水平條：攻擊幾次。**
  - 每次點在接受範圍內就命中一下，連擊繼續。
  - 武器等級與屬性決定一次連擊最多幾下。
- **屬性：**
  - **AGI** 縮短攻擊之間的**等待時間**，AGI 越高，同樣的時間內玩家能攻擊越多次。**負責人（2026-10-20）**；這就是
    AGI 目前的效果（縮短能量條冷卻）。指標的速度來自集氣與武器，不是 AGI；
  - **DEX** 決定接受範圍（目前 DEX 已經會加寬命中區）。
- 指標以 **tween** 移動（「use tween to move the lighting indicator」）。
- **攻擊時計時暫停。負責人（2026-10-20）：**玩家或敵人在攻擊時（攻擊與它的動畫），**雙方**的攻擊計時都暫停，直到
  那次攻擊結束。任何一方都不會在自己的連擊中途被打，動畫播放時也不會浪費時間。

核心是取捨：集氣越多傷害越高，但指標越快，連擊越難。

## 5. 武器

**負責人（2026-10-20）：**戰鬥的玩法取決於武器；每種武器有自己的玩法。

### 5.1 空手：移動條上的五個點

```
1---2---3---4---5        指標來回移動；點的數量隨等級增加（最多五個）
```

- 指標在點上時點擊。每命中一下連擊加一段；升級會增加點的數量，最多五個。
- **指標會返回**，所以沒點到的點還能補救，而且不要求順序。例如：點了 1，2、3 沒點到，繼續點 4、5；指標返回到 3，
  可以從那裡接續。
- 連續兩次沒點到，或亂點，就算**失敗**：出一個普通攻擊，回合結束。
- miss 讓連擊退回多少，取決於武器的等級（5.6 節）。

### 5.2 劍：多邊形上的點，沒有第二次機會

- 命中點在多邊形線條交疊的位置。
- 指標**不會返回**：沒點到就是 miss。
- miss 之後主角要**收劍**：等待較久。
- 劍的連招是**一條可以一直延伸的直線**。武器等級越高，可以連的招式越多。
- 武器等級與主角的劍**熟練度**會改變特效、動畫與攻擊力。

### 5.3 魔杖：依序出現的圈圈（像《應援團》）

- 圈圈依序出現，要在時間內點擊。
  - 依完成度評分。
  - 攻擊與對應的動畫依分數決定。
- **需要聚氣**，所以魔杖比其他武器花更多時間才能攻擊。
- **連段會成長：**第一次攻擊是三段；三段都連到會變成四段；四段都連到會變成五段。
- 等級高或熟練度高時，可以提早點**出招按鈕**，不用每次都連完那麼多段。
- **隨時間長出來的線：**例如四條線依序生長出來，命中點依同樣順序演出。先把這種時間差碰撞與在正確時間顯示的
  「魔術數字」搞定（第 9 節）。

### 5.4 有名字的招式（第一人稱拳擊視角）

來自 2024 年 6 月的段落：
- 視角像第一人稱拳擊遊戲，再往後拉一點，玩法像《應援團》。
- 連擊會出現**招式的多選項**：
  - 打得好是「虎虎生風四連擊」；
  - 打不好就變成「虎頭蛇尾」，攻擊威力比較小。
- 適用於所有武器（提案）：每個連招結果都有名字，讓玩家同時看到自己做到了什麼、錯過了什麼。

### 5.5 三種新武器（提案，依筆記要求）

| 武器 | 怎麼打 | 熟練度與等級帶來什麼 |
|---|---|---|
| **弓：按住再放開** | 按住拉弓，準星在敵人身上擺動，準星經過弱點時放開。拉越久傷害越高，但準星擺得越快（與第 4 節相同的取捨） | 每次放箭的箭數增加（2 支，再 3 支）；「完美放箭」的時間窗隨熟練度變寬；進階：蓄力穿透箭，打中整群敵人 |
| **戰鎚：畫出形狀** | 在時限內沿敵人身上顯示的形狀滑動（直線、V 字、鋸齒）。準確度就是威力。這就是 2024 年 2 月的筆記「打敵人時手滑出特殊形狀的路徑」 | 更難的形狀解鎖更大的重擊；熟練度放寬路徑的容許範圍；進階：震地，讓敵人暈眩 |
| **雙刃：節奏點擊** | 隨著越來越快的節拍左右交替點擊。每拍準時就命中一下；沒跟上拍子連擊就斷 | 每串連擊的拍數增加；完整連擊結尾有終結技；進階：每次命中附加毒（持續傷害）。雙刃匕首已經是遊戲中的道具，這讓它有自己的玩法 |

這張表中的每種武器也都有：
- 失敗結果（一個普通攻擊，與空手相同）；
- miss 的恢復代價（以劍的「收劍」等待為範本）；
- 有名字的招式（5.4）。

### 5.6 miss 讓連擊退回（所有武器）

**負責人（2026-10-20）：**miss 讓連擊退回較早的一段，退多少取決於武器與它的等級。負責人的例子：

| 武器等級 | miss 讓連擊 |
|---|---|
| Lv 5 | 回到起始 |
| Lv 10 | 退回 5 點 |
| Lv 15 | 退回 4 點 |
| … | 越來越少 |

每種武器在**設定檔**中設定，不用改程式就能調整每種武器的數值。提案：`assets/data/weapon_play.json`：

```json
{
  "unarmed": { "missBack": [ { "lv": 1, "back": "start" }, { "lv": 10, "back": 5 }, { "lv": 15, "back": 4 } ] },
  "sword":   { "missBack": [ { "lv": 1, "back": "start" }, { "lv": 10, "back": 3 } ], "missWaitMs": 1200 }
}
```

- 採用 `lv` 小於或等於武器等級中最高的那一筆。
- `back` 是退回的點數，或 `"start"`。
- 同一個檔案也存放每種武器的其他玩法設定（每級的點數、miss 後的等待……）。

## 6. 武器成長

- 兩個分開的數值：
  - **武器等級：**武器本身的等級，用的次數越多提升越多。
  - **熟練度：**主角對這類武器的熟練。
- 兩者都會提升效果。熟練度會解鎖捷徑，例如魔杖的提早出招。
- **進階：**有的武器可以進階成更強的型態。
- **手機玩家的節奏：**
  - 初階升級要快（每級幾場戰鬥）；
  - 進階後升級要慢慢來。

  曲線範例**（提案）**：

  | 階段 | 升到下一級需要的使用次數 |
  |---|---|
  | 初階，Lv 1–5 | 5、8、12、16、20 |
  | 進階，Lv 1–10 | 40，之後每級 +15 |

- **升級的體驗：**本來只能連兩下的招式變成三下。升級後立刻展示新招式，讓玩家感受到。

## 7. 一開始選擇攻擊方式

- 故事一開始有一個事件，讓玩家**選擇攻擊方式**，也就是起始的武器類型。
- 武器跟攻擊模式有關。**負責人（2026-10-20）：**戰鬥的玩法取決於武器。
- **負責人（2026-10-21）：**難易度**不**和這個選擇掛勾，而且**遊戲中可以更改**。選的是主要的攻擊方式；
  之後仍可以撿到並使用其他武器。

## 8. 其他模式（之後再做）

**負責人（2026-10-20）：**它們是 **TOMS 的一部分**，但每個都做成**獨立的模組**，讓其他遊戲可以重複使用：有自己的程式
資料夾與資料，只透過一個小介面和 TOMS 溝通（開始、結果、傳入玩家的能力值），不碰 `Game` 的內部。

- **2024 年 5 月：橫向掛機。**
  - 主角由一個方向一直往另一個方向前進；上方保持在遇到敵人（一隻或一群）的小地圖。
  - 下方出現戰鬥畫面。
  - 玩家不下指令的話，時間到了主角會依自己的能力值自動攻擊。
  - 自己用指令打會比較快。
- **2024 年 6 月：迷宮鬼抓人。**
  - 一開始顯示整張迷宮大地圖，每條路都有來與去兩條。
  - 玩家前往終點，自己決定要不要繞路撿寶箱。
  - 玩到後面會有越來越多鬼來抓玩家。
  - 有的牆壁可以爆破抄捷徑。

## 9. 筆記要求的工具與引擎工作

- **武器測試模式：**一個不進入故事的新 phase，可以直接和指定的怪物戰鬥，測試武器手感。它也是開發者調整數值的地方。
- **教學：**每次獲得新武器時，可以練習它的小遊戲。
- **所有狀態的動畫：**集氣、命中、miss、失敗、連段提升、收武器、出招。
- **先處理時間差命中：**先解決時間差碰撞與在那些時間點顯示的數字，再做武器（5.3 的生長線）。
- **安全的 `setTimeout`：**延遲呼叫不能在物件被銷毀之後執行。筆記建議用 `shared_ptr` 加 `std::map<pointer, function>`，
  呼叫完成後從 map 移除。**（提案）**用擁有者憑證即可：延遲呼叫保存一個 `weak_ptr`（或一個 id，對照存活物件表檢查），
  擁有者已不在就什麼都不做。

4. **空手 miss：**是指標返回可以補救（較新的筆記），還是連擊回到起始（較早的一行）？
5. **敵人的回合：**玩家連擊時，敵人繼續依自己的計時攻擊（如目前），還是等待？
6. **其他模式**（第 8 節）：是 TOMS 的一部分（活動樓層、小遊戲），還是獨立的遊戲？

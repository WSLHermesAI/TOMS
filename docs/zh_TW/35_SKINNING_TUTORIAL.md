# 教學：在動畫編輯器中做蒙皮、變形與權重手繪

這份教學一步一步帶你在動畫編輯器裡讓 sprite 彎曲：

- **蒙皮**：sprite 隨骨頭彎曲。
- **變形**：用晶格把 sprite 壓扁、拉長。
- **權重手繪**：由你決定哪根骨頭帶動 sprite 的哪個部分。

不需要寫程式。範例使用遊戲圖集裡現成的 golem（石像）sprite。做完後，你會得到一個腰部擺動、會點頭、會呼吸的石像。

內部原理與所有選項在 [34_MESH_ANIMATION.md](34_MESH_ANIMATION.md)。編輯器的基本操作（片段、節點、關鍵影格）在
[15_ANIMATION.md](15_ANIMATION.md)。

---

## 0. 本文用語

| 用語 | 意思 |
|---|---|
| **節點** | 動畫中的一個項目：一張 sprite，或讓其他節點掛在底下的空「群組」。**節點**面板以樹狀顯示它們。 |
| **骨頭** | 讓 sprite 彎曲的空節點。骨頭從自己的點延伸到它底下的下一根骨頭，畫成一條彩色的線。 |
| **蒙皮** | 讓 sprite 彎曲的骨頭清單。有蒙皮的 sprite 稱為**已蒙皮**。 |
| **網格** | 把 sprite 切成小三角形，才能彎曲。編輯器會依 sprite 的圖自動產生。 |
| **權重** | 網格上一個頂點跟隨某根骨頭的程度：0 = 完全不跟隨，1 = 完全跟隨。每個頂點的權重加起來是 1。 |
| **晶格** | 蓋在 sprite 上的一格格控制點。移動控制點會把附近的圖壓扁或拉長。 |
| **關鍵影格** | 在時間軸某個時間存下的值。編輯器會在關鍵影格之間平滑過渡。 |
| **播放頭** | 目前的時間，顯示在下方的**播放控制**列上。點擊或拖曳即可移動。 |
| **自動關鍵影格**（N） | 開啟：你做的每個修改都在播放頭寫入關鍵影格（你在*做動畫*）。關閉：修改的是靜止時的樣子（你在*搭骨架*）。 |

常用按鍵：

| 按鍵 | 作用 |
|---|---|
| O / B / L / P | 物件、骨頭、晶格、權重模式 |
| W / E / R | 移動、旋轉、縮放工具 |
| N | 開關自動關鍵影格 |
| K | 在播放頭插入關鍵影格 |
| Space | 播放／暫停 |
| F | 讓畫面符合內容 |
| Ctrl+Z | 復原 |
| 右鍵拖曳、中鍵拖曳或 Space+拖曳 | 平移畫面；滑鼠滾輪縮放 |

## 1. 開啟教學的起始檔

教學附有兩個檔案，在 `docs\examples\tutorial\`：

| 檔案 | 內容 |
|---|---|
| `golem_start.anim` | 你的起點：放在 `stage` 節點上的石像 sprite（`stage` 讓它放大 4 倍顯示）、一個 1 秒循環的片段 `idle`，此外什麼都沒有 |
| `golem_done.anim` | 你的終點：骨頭、蒙皮、手繪權重、擺動、點頭與呼吸。想比對時隨時開啟 |

1. 啟動編輯器：`Editor\AnimEditor.cmd`，或 `Build\windows-release\bin\anim_editor.exe`。
2. **說明 > 開啟教學起始檔**。石像會出現，站在畫面的中線上。
3. **檔案 > 另存新檔…**，在同一個資料夾存成 `my_golem.anim`。這樣你在自己的副本上操作，起始檔保持原樣，下次還能再用。
   請留在那個資料夾：檔案是從那裡找到遊戲圖集的。

**說明 > 蒙皮教學**（F1）會開啟這一頁。**說明 > 開啟教學完成檔**會開啟完成的石像。

> **想從零開始做自己的動畫？** **檔案 > 新增**、**檔案 > 另存新檔…**（編輯器會在檔案旁記下圖集的位置，所以要先存檔）、
> **檔案 > 加入圖集…** 並選擇 `assets\media\atlas\game.atlas`。然後從**精靈圖**面板把 sprite 拖進畫面，按 **F2** 替節點命名。

---

## 2. 四處看看

1. 在**節點**面板會看到 `stage`，底下是 `golem`。點選 `golem`：**屬性**面板會顯示它的 sprite、位置，以及空白的**蒙皮**欄。
2. 按 **Space**：還不會動，片段沒有關鍵影格。
3. 轉動滑鼠滾輪縮放，右鍵拖曳平移。**F** 讓畫面重新符合內容。

---

## 3. 建立骨頭

骨頭放在節點樹中 sprite 的**底下**：這樣移動石像時，骨頭會跟著一起動。每根骨頭放在前一根底下，串成一條鏈：

```
golem          （sprite）
  hip          （骨頭 1：腰）
    chest      （骨頭 2）
      head     （骨頭 3）
```

1. 在節點面板選取 `golem`。
2. **節點 > 加入子節點**（Ctrl+Shift+N）。按 **F2**，命名為 `hip`。
3. 選取 `hip`，再加入一個子節點，命名為 `chest`。
4. 選取 `chest`，再加入一個子節點，命名為 `head`。

骨頭是空節點：它們沒有圖。

---

## 4. 替 sprite 加上蒙皮

1. 選取 `golem`。
2. 在**屬性**面板的**蒙皮**欄輸入骨頭，以逗號分隔：`hip, chest, head`，按 Enter。
3. 看看底下的說明。應該會寫類似「網格：25 個頂點、… 個三角形。3 根骨頭，權重：自動」。這表示編輯器已從石像切出網格，並自己算好了權重。

如果說明寫的是別的：

| 說明寫著 | 怎麼做 |
|---|---|
| 「此精靈圖沒有網格…」或「…在圖集中是旋轉的…」 | 這張 sprite 無法彎曲；換一張 sprite。 |
| 「不是此片段的節點：…」 | 骨頭名稱打錯了。修正蒙皮欄的文字。 |
| 警告骨頭在 sprite 之外 | 按**把骨頭移到此精靈圖底下**。畫面上不會有任何移動；骨頭現在位於石像底下。 |

**網格格數**（同樣在屬性面板）設定網格切得多細。預設每 8 像素一格。格子越多，彎曲越平滑。可以試試 6 × 8 看看差別，然後按 Ctrl+Z：本教學請保留預設，因為完成檔的手繪權重屬於預設的網格。

---

## 5. 擺放骨頭（靜止姿勢）

這是石像靜止站立時骨頭的位置。自動權重是依這些位置算出來的，所以請仔細擺放。

1. **關閉自動關鍵影格**（N）。屬性面板會顯示 auto-key 為關閉。
2. 切換到**骨頭模式**（B）。骨頭會顯示成彩色的線，每個關節有一個圓點。這個模式下點擊只會選到骨頭，不會選到 sprite。
3. 開啟**檢視 > 顯示蒙皮**（Shift+K）。網格會畫在石像上；每個頂點的顏色是它所跟隨骨頭的顏色。
4. 用**移動**工具（W）把每根骨頭的關節拖到定位：
   - `hip`：身體下方的腰部（完成檔：**位置** 0, -6）；
   - `chest`：再高一點，身體中間（0, -8：在 hip 上方 8 像素）；
   - `head`：脖子（在 chest 上方 0, -8）。

   移動骨頭時頂點的顏色會跟著變：那是自動權重在跟隨它們。若要輸入精確位置，改用屬性面板的**位置**。骨頭的位置是從它上面那根骨頭起算的。

---

## 6. 讓骨頭動起來

現在讓石像動起來。

1. **開啟自動關鍵影格**（N）。
2. 在**片段**面板把片段的**長度**設為 `1` 秒。
3. **開頭的關鍵影格。** 把播放頭放在 0。選取 `chest`（點它的關節），按 **K**。這會在 0 秒存下它的靜止角度。
4. **彎曲。** 把播放頭移到 0.5 秒。選**旋轉**工具（E），拖曳 `chest` 周圍的圓圈，把它傾斜約 14°。0.5 秒會寫入關鍵影格；按住 Shift
   則以 15° 為一格轉動。
5. **回到靜止。** 把播放頭移到 1.0 秒，選取 `chest`，在屬性面板把它的**旋轉** z 輸入 `0`。自動關鍵影格會在 1.0 秒寫入這個值。
6. 對 `head` 做同樣的事：0 與 1 秒設關鍵影格，0.6 秒（比 chest 稍晚）約 -12°，就是點頭。
7. 按 **Space** 播放。在播放控制列開啟**循環預覽**讓它一直播放。

**捷徑：** **關鍵影格 > 動作範本…** 會替你寫好現成的動作。選取 `golem`，選擇：

- `bone_sway`：讓骨頭擺動；
- `nod`：讓最後一根骨頭（頭）點頭；
- `swing`：讓骨頭甩動。

每個範本都是一個復原步驟，可以試試看，不喜歡就復原。

---

## 7. 用權重手繪修正彎曲

播放片段，看看石像哪裡彎得不好：腰像紙一樣對折、頭把肩膀一起拉走。權重手繪可以修正這些。

1. 把播放頭移到彎得最糟的那一格並暫停。任何影格都能畫；看得到問題比較好修。
2. 切換到**權重模式**（P）。
3. 點選要修正的骨頭的**關節**（圓點），例如 `chest`。它的權重會以顏色顯示：

   | 顏色 | 這個頂點… |
   |---|---|
   | 藍 | 不跟隨這根骨頭 |
   | 青、綠 | 跟隨一點／一半 |
   | 黃 | 大多跟隨 |
   | 紅 | 完全跟隨 |

4. 把滑鼠移到網格上。左上角的文字會列出最近的頂點與它的權重，例如「golem 頂點 12：hip 0.62, chest 0.38」。還沒畫之前會加上「（自動權重）」。
5. **繪製：**
   - **拖曳**讓頂點更跟隨這根骨頭（筆刷圓圈是橘色）；
   - **Ctrl+拖曳**讓它們較少跟隨（藍色圓圈）。減掉的權重交給最近的另一根骨頭；
   - **Shift+拖曳**平滑：每個頂點朝鄰居的平均移動（灰色圓圈）。用來柔化兩根骨頭之間生硬的交界。
6. **筆刷：**
   - **`[` 與 `]`** 縮小或放大；工具列的**筆刷**欄可設定精確大小；
   - **強度**（0.01 – 1）是畫一次改變多少，點線內圈表示它。想輕輕修改時，從 0.3 左右開始。
7. 檢查結果：點選另一個關節換骨頭、播放片段（Space），需要的地方再畫。每一筆是一個復原步驟（Ctrl+Z）。
8. 改變主意？**編輯 > 重設為自動權重**會移除那個蒙皮所有手繪的權重。

想看畫好的權重，開啟完成檔（**說明 > 開啟教學完成檔**），按 P 並點選每個關節：腳只跟隨 hip，腰由 hip 與 chest 共享，
肩膀大多跟隨 chest（所以頭點頭時肩膀不動），頭頂只跟隨 head。

**好習慣：**

- 畫那個應該**主導**這塊區域的骨頭。如果頭把肩膀拉走，選 `chest` 把肩膀畫成紅色，而不是把頭骨的權重從肩膀上減掉。
- 兩根骨頭之間保留柔和的過渡（綠與黃）。藍直接接紅的生硬交界會折出尖角。
- 等網格格數確定**之後**再畫。改變格數，或換了形狀不同的新圖，都會產生新網格，手繪的權重會回到自動。

## 8. 用晶格壓扁與拉長（變形）

晶格適用於任何 sprite，不論有沒有蒙皮。適合做呼吸、落地壓扁或果凍效果。

1. 切換到**物件模式**（O），選取 `golem`。
2. 切換到**晶格模式**（L）。石像上會出現一格格黃色的控制點。
3. 在**屬性 > 晶格**選擇格數。4 × 4 是不錯的起點；控制點越多，控制越細。
4. **開頭的關鍵影格，什麼都沒動。** 把播放頭放在 0。在**關鍵影格**面板點選**變形**（Deform）欄的一格，然後按 **K**。
5. **吸氣。** 把播放頭移到 0.5 秒。把最上面一排控制點往上拖幾個像素。移動過的控制點會變成橘色，並在播放頭寫入變形關鍵影格。
   （拖曳晶格一律會寫入關鍵影格，與自動關鍵影格開關無關。）
6. **吐氣。** 把播放頭移到 1.0 秒，再點一次變形欄並按 **K**：回到什麼都沒動。
7. 按 Space 看它呼吸。

要微調時，關鍵影格面板的**變形**欄會把移動過的控制點以文字顯示，例如 `5: 0, -2; 6: 0, -2`，表示控制點 5 與 6 往上移了 2
像素。可以直接編輯這段文字。

**捷徑：** 對石像使用**關鍵影格 > 動作範本…**，也有晶格範本：`breathe`、`sway`、`squash`、`jelly`。

**晶格與骨頭一起用：** 晶格先讓圖變形，然後骨頭再帶著它走。請在骨頭處於靜止的影格（沒有轉動時）拖曳晶格；否則控制點會對不上圖。

## 9. 存檔並在遊戲中使用

1. **檔案 > 儲存**（Ctrl+S）。編輯器也會把石像的網格加進圖集的網格檔（`assets\media\atlas\game.mesh.json` 與 `.bin`）。
   遊戲從那裡讀取網格；你不需要做其他事。
2. 檢查檔案：
   ```
   anim_editor --headless check docs\examples\tutorial\my_golem.anim
   ```
   它會回報打錯的骨頭名稱，或沒有網格的蒙皮 sprite。
3. 圖集重建或換風格（新的美術）之後，一次更新所有網格：
   ```
   python tools\refresh_meshes.py
   ```
   只要新網格的頂點數不變，手繪的權重就會保留；否則那張 sprite 會回到自動權重，需要重新繪製。

## 10. 看起來不對時

| 問題 | 原因與做法 |
|---|---|
| sprite 沒有彎曲，只是移動 | 它沒有蒙皮（屬性 > 蒙皮是空的），或沒有網格（看看蒙皮欄底下的說明）。 |
| 骨頭模式什麼都沒顯示 | 只有已蒙皮的 sprite 才會顯示骨頭。先加上蒙皮（第 4 步）。也確認 sprite 是可見的，沒有被「單獨」（Solo）藏起來。 |
| 移動骨頭改的是靜止位置，不是關鍵影格 | 自動關鍵影格是關的（N）。擺放骨頭時（第 5 步）這樣是對的；要做動畫時請打開（第 6 步）。 |
| 在權重模式點擊時選到了骨頭，而不是繪製 | 你點到了關節的圓點。從離它遠一點的地方開始畫。 |
| 權重模式沒有顯示顏色 | 選取蒙皮中的一根骨頭：點它的關節，或在節點面板選它。顏色只顯示選取的骨頭所在的蒙皮。 |
| 一筆改到了兩張 sprite | 筆刷會畫它底下所有含有選取骨頭的蒙皮。用節點面板的**單獨**（Solo）只顯示其中一張。 |
| 手繪的權重不見了 | 網格改變了（新的網格格數或新的圖），所以回到了自動。請重新繪製。 |
| 晶格控制點沒有落在圖上 | 這個影格骨頭有轉動。請在骨頭靜止的影格拖曳晶格。 |

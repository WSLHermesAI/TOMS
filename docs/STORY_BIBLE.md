## 0. 一句話概要

**一位在修真界巔峰被摯友背刺而隕落的大帝，以秘術轉世重生為此界一名毫無修為的見習巫師；他必須攀上七十層巫師之塔，在漫長的攀升中逐層解開被封印的記憶與修為，最終面對那位在此界稱王的背叛者——而每一次死亡，都會讓他以「半力」再入輪迴。**

## 1. 世界觀

### 1.1 兩界並存

| 界域 | 名稱 | 性質 | 與故事關係 |
|---|---|---|---|
| 上界 | **九霄修真界** | 修士以氣煉身：引氣 → 築基 → 金丹 → 元嬰 → 化神 → 大帝 | 主角與仇人的來處 |
| 此界 | **安穩之國** | 凡人國度，唯巫師能借「星核」之力施法 | 今生舞台；巫師之塔即建於星核之上 |

### 1.2 安穩之星與巫師之塔

- 十年前，黑巫師之王 **沃卡司（Vorkath）** 以禁咒封印「安穩之星」（此界星核／靈脈之心），大地凋零、妖物橫行。
- 反咒之鑰鎖在塔頂囚室，與 **莉歐拉（Liora）公主** 的血脈相繫。
- **真相**：十年前那道禁咒**同時封住了主角的記憶與修為**——星核與主角，是被同一道咒鎖住的兩個囚徒。
- **塔的結構**：塔不是建築，而是**一道咒的實體化**。七十層＝**七十道結**；十個大結（十道封印之鎖）各由七層小結纏繞而成。

### 1.4 九轉輪迴訣（本作重玩機制的世界觀依據）

主角隕落前施展的秘術《九轉輪迴訣》護住一線元神。它的代價是：

1. **記憶逐層取回**（故事進度）；
2. **修為歸零重煉**（成長曲線）；
3. **每一次身死，元神依秘術再入輪迴——但只能帶走一半**（New Game+ 半力重來）；
4. **身外之物無法隨行**（裝備、道具、鑰匙、素材全部重置）；
5. 秘術共**九轉**——九轉用盡者，元神再無可依（見結局 E10）。

> 這條設定同時解釋了「為何重玩會變弱」、「為何道具會消失」，並讓重玩本身成為敘事的一部分：**主角不是在被懲罰，而是在用僅存的元神反覆攀塔。**

**設計原則**
1. **壞結局不是失敗畫面**：每個壞結局都有完整敘事與專屬插圖式結尾文字，讓玩家願意收集（像「來看這條路線會怎樣」）。

## 8. 輪迴（New Game+）：半力重來，物品全清

### 8.1 觸發與規則

- 任一結局（**除 `e_10` 魂飛魄散**）結束後，可選擇「**入輪迴**」重新開始第 1 層。
- **帶走的（一半的力量）**：

| 項目 | 輪迴後 |
|---|---|
| 修為層數（`cultivationTier`） | `floor(舊值 ÷ 2)`（例：大帝 → 金丹） |
| 已學技能 | **保留**，但每個技能的數值效果 × 0.5（取整到最小單位；純解鎖型技能如「引氣」保留全效） |
| 技能點 | `floor(總獲得點數 ÷ 2)` 可重新分配 |
| 攻擊／防禦基礎加成 | × 0.5 |
| 必殺充能上限 | `floor(舊值 ÷ 2)`（最少 1） |
| 記憶碎片 | **保留全部**（敘事上：記憶不因輪迴消失；且 `shard_memory` 影響 `e_07`） |
| 輪迴印記 `cycleMark` | 每輪 +1（`cycleIndex` 亦 +1，上限 9） |

- **清空的（身外之物）**：

| 項目 | 輪迴後 |
|---|---|
| 裝備（含已鍛造武器／防具／護符） | **全部重置**為起始 `wand` |
| 消耗品、鑰匙、素材、寶石 | **全部清空** |
| 金幣 | 歸零 |
| 鍛造圖譜／主動技 | **保留圖譜與已獲得的主動技知識**，但需重新取得材料與裝備才能灌注（避免重複農相同支線） |
| 支線完成狀態 | 重置（可再玩一次，但**已看過的結局與提示保留在 meta**） |
| 主線旗標／分歧 | 重置（新一輪可做不同選擇） |

### 8.2 每輪的變化（讓重玩不是單純重複）

1. **敵人強度**：每輪 +15%（上限 +120%，第 8 輪封頂）；精英與群體戰比例提高。
2. **樓層變體**：每輪隨機替換 20% 的樓層為「**前世迴響**」變體（場景重組、敵人改為前世道兵、事件池改抽前世相關條目）。
3. **記憶迴響**：已看過的記憶碎片可「重看」，並解鎖一句前世對話（累積成 `e_01` 的線索）。
4. **結局鎖定**：部分結局需要特定輪數——`e_01` 需第 9 輪；`e_09`／`e_11` 需第 2 輪以上（因為需要「知道真相卻仍然選擇」）。
5. **輪迴錄（meta UI）**：記錄 `cycleIndex`、已看過的結局、已解鎖的提示、`endings_seen[]`。

### 8.3 難度與敘事的平衡

- 輪迴後戰力約為原本 50%，但敵人 +15%→ 實際體感難度提高約 1.3 倍；玩家需要**用不同技能組合與路線**應對（而非單純重複）。
- **半力**是刻意的：秘術只能保住一半元神，因此輪迴後的攀塔更艱難，而 `e_01` 的九轉之路本身就是「用九次半力換一次完整」。

## 9. 主題與基調

- **核心命題**：取回力量與成為人，哪一個才是不負此生？前世的自己是資產還是枷鎖？
- **70 層的節奏意義**：長度不是折磨，而是讓「選擇累積成命運」——玩家會在不知不覺中決定自己是誰。
- **反派**：不是邪惡，而是另一種正確。
- **禁忌**：不用「命中注定」解釋主角的強；每一分力量都必須對應**記憶碎片＋系統解鎖**。
- **莉歐拉**：必須有自身意志（`ss_10`、`e_03`、`e_15` 皆建立在她主動選擇之上）。

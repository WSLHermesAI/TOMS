Formula: while held, speed(t) = V0 + (Vmax−V0)·(t/rampTime)³ — a cubic ease-in, so it's very slow at first, visibly speeds up, then BOOSTs to near-max speed once t approaches rampTime. The marker starts at one edge and bounces back and forth for as long as the button is held; release freezes it. Power is driven by distance from the bar's center (dead center → 100% power, either edge → 0%), where green/blue/red are three independently adjustable radii from that center — greenHalf (default 15), blueOuter (default 35), redOuter (default 60, which also defines the bar's own edge/length). A weapon/armor can set any of the three, or stretch/shrink rampTime — see MAIN_BATTLE_SCENE_DESIGN.md §4.

# 支線故事設計集（SIDE STORIES）v3

> 搭配 `docs/story/STORY_BIBLE.md`（70 層／10 幕／15 結局）與 `docs/story/STORY_DATA_SCHEMA.md`。
> 本檔定義：**10 條旗艦支線（sublime story，每幕一條、全部可選）** ＋ **每層小事件池（支撐 70 層的日常內容）** ＋ 支線與結局的耦合規則。

---

## 0. 設計規則

1. **每幕一條旗艦支線**（10 幕 × 1 條），固定落在該幕的**第 5 層**（`ss_10` 為跨幕長鏈）。不完成也能通關。
2. **一條支線 = 一個具體收穫**：技能／裝備＋專屬主動技／鍛造圖譜／樞紐 NPC／關鍵道具，至少一項；**不得只給金幣或經驗**。
3. **深度 3–5 步、5–12 分鐘**（70 層的長度需要支線也略長）。
4. **兩種主線耦合方式**：
   - **限定（gated）**：只有某條路線才出現（`ss_09` / `ss_10`）。
   - **顯影（mirror）**：一定出現，但內容或獎勵反映主線已做過的選擇（`ss_01`/`ss_02`/`ss_04`/`ss_05`/`ss_07`）。
5. **不阻塞主線**；放棄後狀態為 `declined`，可再次觸發。
6. **每層小事件池**（§12）承擔日常內容：70 層若只有 10 條支線會過於空洞，故每層另抽 3–12 個小事件。

## 1. `ss_01` 半塊餅（F5・第一幕・村莊外緣）

| 欄位 | 值 |
|---|---|
| 觸發 | 村莊樞紐開放後，村口井邊蹲著一個盯著枯井的孩子 |
| 步驟 | ① 對話（他要的是吃的，不是錢）② 給 `potion_red`／`coin`／不給 ③ 若給予 → 母親**小穗**現身 |

**故事**：孩子的父親十年前上了塔，沒回來。他不哭，只是每天在井邊等。主角在前世見過太多這種等待。

**顯影 `c_motive`**
- 求知 →「我要先知道我為什麼在這裡。」→ 孩子：「那你跟我爹一樣。」
- 救公主 →「我要救她。」→ 孩子：「謝謝你。」
- 先報仇 → 誠實說出 → 孩子沉默後把餅分一半：「那你吃飽一點。」

**收穫**：`hub.village` 新增 NPC `npc_xiaosui`（小穗），商店折扣 10%，並成為後續 70 層的凡人視角對話人物。

## 12. 每層小事件池（70 層的日常內容來源）

> 旗艦支線只有 10 條，因此每層的事件點（3–12 個，見 `docs/story/STORY_BIBLE.md` §5）由**事件池**抽樣。事件池分為「通用池」與「幕限定池」，抽樣規則由生成器執行。

### 12.1 事件型態（`eventKind`）

| 型態 | 說明 | 範例 |
|---|---|---|
| `relic` 前世迴響 | 一段前世殘影，給予記憶／敘事 | 殘破的劍痕、雲海上的琴聲 |
| `whisper` 亡者低語 | 提供世界觀與伏筆 | 「那位大人……十年前來過這裡」 |
| `cache` 隱蔽寶箱 | 素材／消耗品／金幣（依樓層縮放） | 藏於牆後、需解鎖的寶箱 |
| `rescue` 可救助 NPC | 救出後於樞紐出現／給予情報 | 被困的士兵、被咒的少年 |
| `trap` 機關 | 陷阱／限時挑戰 | 落石通道、毒霧房 |
| `merchant_echo` 商人殘影 | 以物易物（不收金幣，收素材） | 前世商人的殘影 |
| `memory_shard` 記憶碎片 | 主線必經（7 片）與散落碎片 | 各幕記憶 |

### 12.2 抽樣規則（生成器輸入）

```
events(F) = 通用池[樓層縮放] × 40% + 幕限定池 × 40% + 主線碎片(若有) × 20%
數量     = 依 STORY_BIBLE §5 的「事件點」欄（F1 為 3 → F70 為 12）
去重     = 同層不得重複同一 eventId
```

### 12.4 小事件與結局

- 小事件**不直接**影響結局計數器（避免玩家被迫清空每層），但其中 15% 為 `choice` 型（例如救助／放棄、拾取／留給亡者），**會** ±1 計數器。
- 每層至少保證 1 個 `relic` 或 `whisper`（敘事感），1 個 `cache`（成長感）。

## 13. 獎勵與平衡（70 層尺度）

| 收穫類型 | 來源 | 強度定位 |
|---|---|---|
| 被動技能 | `ss_02`、`ss_10` | 手感／終局強化 |
| 主動技能 | `ss_04` | 中階輸出 |
| 裝備主動技 | `ss_05`、`ss_08`、`ss_09` | 保命／防禦／爆發 |
| 鍛造圖譜 | `ss_03`、`ss_07` | T2／T3 武器線 |
| 強力武器 | `ss_09` | T4 高技巧高回報 |
| 素材 | `ss_06` | 二次強化 |
| 樞紐 NPC | `ss_01`、`ss_07` | 經濟與鍛造 |
| 技能點 | `ss_06`/`ss_07` 各 2 | 通用成長 |
| 關鍵道具 | `ss_08`（星核碎晶）、`ss_10`（反咒之鑰捷徑） | **結局必要** |

**平衡原則**：10 條旗艦支線全完成的額外戰力約主線自然成長的 **25–30%**；但因**輪迴會清空裝備並減半技能**（見 `docs/story/STORY_BIBLE.md` §8），支線獎勵只在**當前輪**有意義，不會造成多輪後的數值膨脹。

## 14. 支線資料的產生方式

1. 每條支線於 `data/missions.json` 產生一筆 `kind: "side"` 條目（`stageId` = 樓層 id，如 `F05`）。
2. 觸發點寫入該層 `stage.story.sideStoryHooks[]`。
3. 對話沿用 `data/dialogue/*.json` 節點格式。
4. 限定開放以 `choiceMade` 條件表達：
   ```json
   { "type": "choiceMade", "choiceId": "c_final_stance", "optionId": "opt_guard" }
   ```
5. 顯影以節點內條件分支表達（同一 id、同一份資料）。
6. 小事件以 `data/events/pool_<act>.json` 定義，生成器依 §12.2 規則寫入每層的 `stage.story.events[]`。
